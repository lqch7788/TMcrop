# 农业种植管理系统 V1.1 - 系统介绍PPT

## 1. Canvas Format
- **Format**: PPT 16:9 (1280×720)
- **Aspect Ratio**: 16:9

## 2. Target Audience
- **Primary**: 软件开发人员 - 需要理解系统架构、功能模块、数据流、审批流程
- **Secondary**: 领导/管理层 - 需要了解系统整体作用、核心功能、业务流程

## 3. Style Objective
- **商务正式风格** - 简洁、专业、层次清晰
- **配色方案**: 绿色农业主题 (主色: #10B981 翠绿色, 辅色: #059669 深绿色, 点缀: #F59E0B 橙黄色)
- **图标风格**: Lucide React图标库，简洁线条风格
- **字体**: 中文使用系统默认字体，英文使用Arial

## 4. Page Count & Structure (约25-30页)

### 目录结构
1. **封面** - 系统名称、版本、日期
2. **目录** - 内容概览
3. **系统概述** - 系统定位、核心价值
4. **系统架构** - 整体架构图
5. **技术栈** - 前后端技术选型

### 模块介绍 (核心部分，约15页)
6. **计划管理模块** - 生产计划、技术方案、采购计划
7. **作物管理模块** - 种源、育苗、种植、采收、库存
8. **农事管理模块** - 任务中心、巡查记录、问题管理
9. **人工管理模块** - 考勤、人事、薪酬、运营分析
10. **库存管理模块** - 物料入库、出库、供应商
11. **审批中心模块** - 审批类型、审批流程
12. **生产汇总模块** - 报表、统计、分析
13. **系统设置模块** - 权限、角色、字典配置

### 流程详解 (约8页)
14. **审批流程** - 审批类型、流程图
15. **任务流转** - 农事任务生命周期
16. **数据流** - 核心数据流向
17. **生产批次流程** - 从计划到采收

### 数据库架构 (约3页)
18. **数据库表结构** - 核心表关系
19. **API接口** - 主要接口列表

### 总结 (约2页)
20. **系统特性总结**
21. **联系方式**

## 5. Color Scheme
- **Primary**: #10B981 (Emerald Green - 农业主题)
- **Secondary**: #059669 (Deep Green)
- **Accent**: #F59E0B (Amber - 警示/重点)
- **Background**: #FFFFFF (白色背景)
- **Text Primary**: #1F2937 (深灰文字)
- **Text Secondary**: #6B7280 (浅灰文字)
- **Border**: #E5E7EB (边框)

## 6. Typography
- **Title**: 28-32px, Bold, #1F2937
- **Subtitle**: 20-24px, SemiBold, #374151
- **Body**: 14-16px, Regular, #4B5563
- **Caption**: 12px, Regular, #9CA3AF

## 7. Page Rhythm
- **封面/目录**: breathing (留白多，视觉冲击)
- **模块介绍**: anchor (卡片式布局，信息密集)
- **流程图**: dense (紧凑，完整展示)
- **总结页**: breathing (收尾，简洁有力)
