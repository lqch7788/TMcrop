## 五、旧系统字段缺失

### 种源管理
- ❌ `ProveanceType` — 来源分类（外购/自繁/留存/调拨/试验）
- ❌ `SeedlingNum` — 育苗消耗数量（用于自动扣减展示）
- ❌ 质检信息 — 发芽率/纯度/净度/水分含量/质检日期

### 育苗管理
- ❌ `BreedType` — 育苗方式细分
- ❌ `nurserySite` — 育苗地点
- ❌ `FixPlantTime` / `PlantFinish` — 定植相关时间
- ❌ `SeedlingWorkTime` — 育苗作业时间

### 种植管理
- ❌ `TransPlantNum` / `TransPlantPH` / `TransPlantEC` — 移栽时数据
- ❌ `FixPlantNum` / `FixPH` / `FixEC` — 定植时数据
- ❌ `HarvestFinish` / `Harvest time` — 采收完成标记
- ❌ 传感器数据 — 空气温湿度/光照/CO₂/土壤温湿EC PH

## 七、编码体系（当前已实现）

| 编码类型 | 格式 | 示例 |
|----------|------|------|
| 品种编码 | 11位：类别(2)+类型(2)+品种(2)+子品种(3)+详细(2) | `PD030100400` |
| 种源批号 | ZZ + YYYYMMDD + "-" + NNN | `ZZ20260115-001` |
| 育苗批号 | YM + YYYYMM + "-" + NNN | `YM2026-001` |
| 种植批号 | ZZ + YYYYMM + "-" + NNN + "-" + SS | `ZZ2026-001-01` |
| 实例编码 | 品种编码(9位) + YYMMDD(6位) + NNN(3位) | `PD0301000100240426001` |
| 采收单号 | HS + YYYYMM + NNN | `HS202604001` |
| 操作记录 | OP + YYYYMMDD + "-" + RRRR | `OP20260410-1001` |
