# 任务类型动态配置方案

## Context
用户希望在农事任务表中，当选择特定任务类型（如施肥、植保）后，能够显示该类型的详细配置项。例如选择"施肥"后需要显示肥料种类、用量、稀释倍数等；选择"植保"后需要显示药剂种类、用量、稀释倍数等。这是一个可扩展的动态表单配置需求。

## 设计方案

### 1. 数据结构设计

**新增类型定义文件** `src/types/farm/taskTypeConfig.ts`：

```typescript
// 配置项类型
export type ConfigFieldType = 'text' | 'number' | 'select' | 'multiSelect' | 'textarea';

// 配置项定义
export interface TaskConfigField {
  key: string;           // 字段键名
  label: string;         // 显示标签
  type: ConfigFieldType; // 字段类型
  required?: boolean;
  unit?: string;         // 单位（如 "kg/亩", "倍"）
  options?: { value: string; label: string }[];  // 下拉选项
  dependsOn?: string[];  // 依赖字段（条件显示）
}

// 任务类型配置
export interface TaskTypeConfig {
  value: string;         // 类型值
  label: string;         // 显示名称
  icon: string;         // 图标名
  color: string;        // 颜色类
  configFields: TaskConfigField[];  // 配置项
}
```

**各任务类型配置概览**：

| 任务类型 | 配置项 |
|---------|-------|
| 施肥 | 肥料种类、用法用量、稀释倍数、施用方式 |
| 植保 | 药剂种类、药剂名称、用量、稀释倍数、防治对象、安全间隔期 |
| 灌溉 | 灌溉量、灌溉方式、灌溉时长 |
| 灌根 | 用水量、是否添加肥料 |
| 修剪 | 修剪类型、工具、修剪部位 |
| 定植 | 苗种类、用苗量、种植密度 |
| 采收 | 成熟度标准、预估产量、品质等级 |
| 除草 | 除草方式（人工/机械/化学）、除草深度 |
| 其他 | 自定义备注 |


### 3. 核心实现

#### 3.1 useTaskTypeConfig Hook
- `getConfig(taskType)` - 获取某类型的配置
- `getVisibleFields(taskType, values)` - 获取可见字段（处理依赖关系）
- `getDefaultValues(taskType)` - 获取默认值

#### 3.2 ConfigFieldRenderer 组件
根据 `ConfigFieldType` 渲染不同类型的输入控件：
- `text` → `<input type="text">`
- `number` → `<input type="number">` + 单位显示
- `select` → `<select>` 下拉菜单
- `multiSelect` → 标签式多选
- `textarea` → `<textarea>`

#### 3.3 TaskTypeConfigPanel 组件
- 单选任务类型时显示配置面板
- 多选或未选时显示提示信息

### 4. 实现步骤

**Phase 1 - 类型和数据**（优先级：高）
1. 创建 `src/types/farm/taskTypeConfig.ts` 定义核心类型

**Phase 2 - Hook**（优先级：高）
3. 创建 `useTaskTypeConfig.ts` Hook

**Phase 3 - 组件**（优先级：高）

**Phase 4 - 表单集成**（优先级：中）
7. 扩展 `newTask` 状态，添加 `typeConfig` 字段
8. 配置变化时更新 SOP 模板
