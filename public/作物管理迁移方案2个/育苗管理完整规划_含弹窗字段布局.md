# 育苗管理模块完整规划方案（Node.js + SQLite 版）

> 目标：基于 Node.js + SQLite 后端架构，完整规划育苗管理模块所有页面、弹窗、字段、布局、数据流
> 编码规则：强制采用品种库（produceCodeRule）11位编码体系
> 架构：React SPA ↔ REST API ↔ SQLite

### 2.2 编辑弹窗（EditModal）

**规格**
- 标题：编辑育苗记录 — {seedlingCode}
- 尺寸：xl
- 逻辑：加载现有数据，可修改非计算字段
- **不允许修改**：育苗批号、作物编码（品种库关联）、初始数量（已发生业务）
- **允许修改**：预计日期、场地、负责人、成活数量（每日记录反算）、备注、图片

**字段布局**：同新增弹窗，但禁用字段置灰

**数据加载流程**：
```
打开弹窗 → GET /api/seedlings/{id} → 填充表单
         → GET /api/seedlings/{id}/daily-records → 计算成活数
         → GET /api/pictures?entityType=seedling&entityId={id} → 加载图片
```

│     │ 定植操作 → 创建种植记录 → 更新育苗状态        │                 │

│     └─────────────────────────────────────────────┘                 │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘

### 3.2 新增育苗完整数据流

```
用户填写表单 → 点击保存
    ↓
POST /api/seedlings
    ↓
后端校验：
  1. 种源ID存在？→ GET seed_sources WHERE id = {sourceId}
  2. 品种库编码有效？→ GET crop_varieties WHERE crop_code = {cropCode}
  3. 场地存在？→ 校验 sites 表
    ↓
生成育苗批号：
  YM + categoryCode(2) + typeCode(2) + YYYYMM(6) + "-" + NNN(3)
  例：YMPD032604-001
    ↓
事务开始：
  INSERT INTO seedlings (...)
  UPDATE seed_sources SET available_count = available_count - {initialCount}
  INSERT INTO crop_instances (关联创建)
事务提交
    ↓
返回 { id, seedlingCode }
    ↓
前端刷新列表：GET /api/seedlings?page=1
```

### 3.3 定植操作数据流

```
用户选择记录 → 点击定植
    ↓
GET /api/seedlings/{id} → 校验状态/数量
    ↓
用户填写定植表单 → 确认
    ↓
POST /api/plantings
    ↓
后端事务：
  1. INSERT INTO plantings (...)
     plantCode = ZZ + categoryCode + typeCode + YYYYMM + "-" + NNN + "-" + NN
     例：ZZPD032604-001-01
  2. UPDATE seedlings SET plantedCount += {数量}, status = ?
     IF plantedCount >= survivalCount THEN status = 'completed'
  3. UPDATE seed_sources SET available_count -= {数量}（如来源是种源）
  4. UPDATE crop_instances SET planting_id = {newId}, status = 'planting'
事务提交
    ↓
返回 { plantingId, plantCode }
    ↓
前端：关闭弹窗，刷新育苗列表 + 种植列表
```

## 六、编码规则统一

### 6.1 育苗批号生成规则

```
格式：YM + 类别码(2) + 类型码(2) + YYYYMM(6) + "-" + 流水号(3)

示例：YMPD032604-001
  YM   — 育苗标识
  PD   — 蔬菜类（来自品种库 produceCodeRule）
  03   — 茄果类（来自品种库）
  2604 — 2026年4月
  001  — 当日流水号（该类别该类型下当月第1条）

生成逻辑：
  1. 从品种库解析 cropCode 前4位 → categoryCode + typeCode
  2. 取当前年月 YYYYMM
  3. 查询该月该类型已有记录数 + 1
  4. 组合生成
```

### 6.2 与其他模块编码关联

| 模块 | 编码示例 | 关联关系 |
|------|----------|----------|
| 种源管理 | ZZ20260426-001 | 育苗.sourceCode → 种源.seedCode |
| 育苗管理 | YMPD032604-001 | 种植.sourceCode → 育苗.seedlingCode |
| 种植管理 | ZZPD032604-001-01 | 种植.plantCode 独立生成 |
| 作物品种库 | PD030100400 | 所有模块的 cropCode 统一来源 |
