# 采收产品库存管理系统规划

## 背景

当前系统存在两个独立的数据流：
1. **物料入库** → 物料库存总览（生产投入品：化肥、农药、种子等）
2. **采收入库** → 仅作为记录，没有与库存系统关联

**需求**：将采收入库的产品也纳入库存管理体系，支持：
- 查看采收产品的库存状态
- 设置存储时间预警、存储量预警
- 与库存总览整合查询

## 一、数据模型设计

### 1.1 新建 ProduceInventory 类型

```typescript
// 位置：src/types/inventory.ts

export interface ProduceInventory {
  id: string;                    // 唯一标识
  harvestRecordId: string;        // 关联采收入库记录ID

  // 产品识别
  productCode: string;            // 产品编码（可由采收单号生成）
  cropName: string;                // 作物名称（如：番茄、黄瓜）
  variety: string;                // 品种（如：红果番茄、水果黄瓜）

  // 数量与质量
  quantity: number;              // 当前库存数量
  unit: string;                   // 单位（公斤、盒、箱）
  grade: 'A' | 'B' | 'C';         // 品质等级
  quality: 'excellent' | 'good' | 'average' | 'poor'; // 品质评定

  // 仓库位置
  warehouseId: string;            // 仓库ID
  warehouseName: string;          // 仓库名称
  storageLocation: string;        // 具体存放位置（如：A区-01-03）

  // 时间追踪
  harvestDate: string;            // 采收日期
  storageDate: string;            // 入库日期
  expirationDate: string;          // 过期日期（可计算：入库日期 + 保质期）

  // 预警设置
  alertSettings: {
    enableStorageTimeAlert: boolean;  // 启用存储时间预警
    storageTimeThreshold: number;     // 存储时间阈值（天）
    enableQuantityAlert: boolean;      // 启用库存量预警
    minQuantityThreshold: number;       // 最小库存预警量
    maxQuantityThreshold: number;       // 最大库存预警量
  };

  // 批次追溯
  batchCode: string;              // 生产计划批次号
  greenhouseName: string;          // 种植区域
  plantingMode: string;            // 种植模式

  // 状态
  status: 'in_stock' | 'low_stock' | 'expired' | 'out_of_stock';

  // 操作记录
  inboundRecords: InventoryTransaction[];
  outboundRecords: InventoryTransaction[];
}

export interface InventoryTransaction {
  id: string;
  type: 'inbound' | 'outbound' | 'transfer';
  quantity: number;
  date: string;
  operator: string;
  remarks: string;
}
```

## 三、功能模块设计

### 3.1 产品库存列表页

**功能点：**
- 显示所有采收入库的产品库存
- 支持按仓库、作物类型、品质等级、状态筛选
- 支持按产品名称、批次号搜索
- 显示库存预警状态（正常/预警/过期）

**表格字段：**
| 字段 | 说明 |
|------|------|
| 产品编码 | 由采收单号生成 |
| 产品名称 | 作物名称 |
| 品种 | 如：红果番茄 |
| 规格/等级 | A/B/C级 |
| 库存数量 | 当前库存 |
| 单位 | 公斤/盒/箱 |
| 仓库 | 仓库名称 |
| 存放位置 | 具体货架位置 |
| 存储时间 | 入库至今天数 |
| 预警状态 | 正常/即将过期/已过期 |
| 操作 | 查看/编辑/出库 |

### 3.2 预警系统设计

**预警类型：**

1. **存储时间预警**
   - 设置：存储超过X天预警
   - 触发条件：当前日期 - 入库日期 > 阈值
   - 等级：警告（7天内）/ 严重（超过阈值）

2. **库存量预警**
   - 设置：最低库存量、最高库存量
   - 触发条件：quantity < minQuantity 或 quantity > maxQuantity
   - 等级：低库存警告 / 高库存警告

3. **保质期预警**
   - 设置：保质期天数
   - 触发条件：当前日期 > expirationDate - 预警提前期
   - 等级：即将过期（7天内）/ 已过期

**预警显示：**
- 在产品库存列表中用颜色标记预警状态
- 在仪表盘增加"产品库存预警"卡片
- 支持预警设置配置

### 3.3 库存操作

**入库管理：**
- 从采收入库记录自动生成库存记录
- 支持手动调整库存数量
- 支持库存分配（指定存放位置）

**出库管理：**
- 创建出库单，扣除库存
- 记录出库去向
- 打印出库单
