# 育苗管理编码规则修正方案

> 问题：育苗管理页面的作物编码展示未采用品种库规则，仅显示11位编码字符串，用户无法直观理解编码含义
> 修正目标：所有涉及作物编码的展示、筛选、录入，全部采用品种库（produceCodeRule）规则

---

## 一、问题定位

### 1.1 品种库编码规则（已定义）

```
编码结构：类别(2位) + 类型(2位) + 品种(2位) + 子品种1(3位) + 详细品种(2位) = 11位

示例：PD030100400
  PD — 蔬菜类（类别）
  03 — 茄果类（类型）
  01 — 番茄（品种）
  004 — 红果番茄（子品种1）
  00 — 详细品种序号

完整路径：蔬菜类 > 茄果类 > 番茄 > 红果番茄
```

### 1.2 当前育苗管理的编码问题

| 位置 | 当前展示 | 问题 |
|------|----------|------|
| SeedlingTable 表格 | `{record.cropCode}` 显示 "PD030100400" | 用户看不懂这代表什么作物 |
| DetailModal 详情 | 只展示 `cropName` + `cropVariety` | 没有展示编码对应的完整分类路径 |
| SeedlingFilter 筛选 | 按 `cropName` 文本筛选 | 无法按类别/类型/品种层级筛选 |
| 标签打印 | 可能只打印编码 | 应该打印完整品种路径 |
| 导出Excel | 只导出编码 | 应该导出编码+完整路径 |

```tsx
// src/components/farm/common/VarietyDisplay.tsx
import React from 'react';
import { getVarietyByCode } from '../../../services/cropVarietyService';

interface VarietyDisplayProps {
  cropCode: string;
  showCode?: boolean;      // 是否显示编码
  showFullPath?: boolean;  // 是否显示完整路径
  size?: 'sm' | 'md';
}

export function VarietyDisplay({ 
  cropCode, 
  showCode = false, 
  showFullPath = true,
  size = 'md' 
}: VarietyDisplayProps) {
  const variety = getVarietyByCode(cropCode);
  
  if (!variety) {
    return <span className="text-sm text-gray-400">{cropCode}</span>;
  }
  
  const fullPath = showFullPath 
    ? `${variety.categoryName} > ${variety.typeName} > ${variety.varietyName}${variety.subVariety1Name ? ` > ${variety.subVariety1Name}` : ''}`
    : variety.varietyName;
  
  return (
    <div className="flex flex-col">
      <span className={`${size === 'sm' ? 'text-xs' : 'text-sm'} text-gray-900`>{fullPath}</span>
      {showCode && (
        <span className={`${size === 'sm' ? 'text-xs' : 'text-xs'} text-gray-400 font-mono mt-0.5`>
          {variety.cropCode}
        </span>
      )}
    </div>
  );
}
```

## 三、育苗批号编码规则统一

### 3.1 当前批号格式

```
YM2026-001  （YM + 年月 + 流水号）
```

### 3.2 建议统一格式（与品种库编码关联）

```
格式：YM + 类别码(2位) + 类型码(2位) + 年月(4位) + 流水号(3位)
      总长度：2 + 2 + 2 + 4 + 3 = 13位

示例：YMPD032604-001
  YM   — 育苗标识
  PD   — 蔬菜类（来自品种库类别码）
  03   — 茄果类（来自品种库类型码）
  2604 — 年月（2026年4月）
  001  — 当日流水号

优势：
  1. 一眼看出是什么类别/类型的作物
  2. 与品种库编码体系一致
  3. 便于按类别/类型筛选和统计
```

### 3.3 批号生成函数修正

```typescript
// src/services/seedlingService.ts
import { getVarietyByCode } from './cropVarietyService';

export function generateSeedlingCode(cropCode: string, dateStr?: string): string {
  // 从品种库获取类别和类型码
  const variety = getVarietyByCode(cropCode);
  const categoryCode = variety?.categoryCode || 'OT';
  const typeCode = variety?.typeCode || '99';
  
  // 日期
  const date = dateStr ? new Date(dateStr) : new Date();
  const year = date.getFullYear().toString().slice(-2);
  const month = (date.getMonth() + 1).toString().padStart(2, '0');
  const yearMonth = `${year}${month}`;
  
  // 获取当月该类型流水号
  const seedlings = getSeedlings();
  const prefix = `YM${categoryCode}${typeCode}${yearMonth}`;
  const existing = seedlings.filter(s => 
    s.seedlingCode.startsWith(prefix) && s.cropCode === cropCode
  );
  const seq = existing.length + 1;
  
  return `${prefix}-${String(seq).padStart(3, '0')}`;
}
```

### 4.1 新增按品种库层级筛选

```typescript
interface SeedlingFilters {
  // 现有字段
  cropName: string;
  seedlingCode: string;
  // ...
  
  // 新增：品种库层级筛选
  categoryCode?: string;   // 类别：PD/FR/GR/FL/HB/MG/OT
  typeCode?: string;       // 类型：01/02/03...
  varietyCode?: string;    // 品种：01/02/03...
  subVariety1Code?: string; // 子品种：001/002...
  
  // 或直接用cropCode筛选（最精确）
  cropCode?: string;
}
```

### 4.2 筛选逻辑

```typescript
const filteredData = useMemo(() => {
  return seedlings.filter(item => {
    // 按类别筛选
    if (filters.categoryCode) {
      const variety = getVarietyByCode(item.cropCode);
      if (variety?.categoryCode !== filters.categoryCode) return false;
    }
    
    // 按类型筛选
    if (filters.typeCode) {
      const variety = getVarietyByCode(item.cropCode);
      if (variety?.typeCode !== filters.typeCode) return false;
    }
    
    // 按品种编码精确筛选
    if (filters.cropCode && item.cropCode !== filters.cropCode) return false;
    
    // ... 其他原有筛选条件
  });
}, [seedlings, filters]);
```
