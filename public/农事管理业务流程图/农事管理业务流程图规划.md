### 3.2 图表详细说明

#### 图表01：农事管理模块整体架构图
- **内容**：展示农事任务中心的整体架构，各Tab之间的关系，页面与组件的层级结构
- **元素**：
  - FarmTaskHub（主页面）

  - 各弹窗组件
  - 数据层（localStorage）
  - Hooks层

#### 图表02：任务状态流转图
- **内容**：10种任务状态的完整流转路径
- **状态**：
  - draft（草稿）
  - pending（待接受）
  - accepted（已接受）
  - in_progress（进行中）
  - waiting_acceptance（待验收）
  - completed（已完成）
  - rejected（返工中）
  - failed（任务失败）
  - cancelled（已取消）
  - abandoned（已放弃）
- **流转**：包含正常流转路径和异常流转路径（驳回、超时放弃等）

#### 图表03：F01任务创建流程图
- **起点**：用户点击"新建任务"

#### 图表04：F02任务分派流程图
- **起点**：用户选择任务
- **终点**：保存到localStorage
- **分支**：单个分派 vs 批量分派
- **状态变更**：draft/rejected → pending
- **涉及字段**：assigneeId、assigneeName、dispatchedAt、updatedAt

#### 图表05：F03任务接受-F04执行-F05提交流程图
- **F03接受**：pending → accepted
- **F04执行**：accepted → in_progress，进度更新

## 五、任务状态与操作对照表

### 5.1 状态说明

| 状态 | 值 | 说明 |
|------|-----|------|
| draft | 草稿 | 任务创建后未发布 |
| pending | 待接受 | 已发布，等待执行人接受 |
| accepted | 已接受 | 执行人已接受任务 |
| in_progress | 进行中 | 任务正在执行 |
| waiting_acceptance | 待验收 | 执行人提交，等待验收 |
| completed | 已完成 | 验收通过 |
| rejected | 返工中 | 验收驳回，需返工 |
| failed | 任务失败 | 2次返工后仍不通过 |
| cancelled | 已取消 | 任务被取消 |
| abandoned | 已放弃 | 超时后执行人放弃 |

### 5.2 操作与状态变更

| 操作 | 触发条件 | 状态变更 | 说明 |
|------|---------|---------|------|
| create | 新建任务 | - | 创建草稿 |
| publish | 发布任务 | draft → pending | 发布已填写的任务 |
| assign | 分派任务 | draft/rejected → pending | 指定执行人 |
| accept | 接受任务 | pending → accepted | 执行人接受 |
| start | 开始执行 | accepted → in_progress | 开始工作 |
| progress | 更新进度 | in_progress（不变） | 仅更新进度 |
| submit | 提交验收 | in_progress → waiting_acceptance | 完成工作申请验收 |
| complete | 验收通过 | waiting_acceptance → completed | 验收人通过 |
| reject | 验收驳回 | waiting_acceptance → in_progress/rejected | 验收人不通过 |
| continue | 继续执行 | rejected → in_progress | 返工后继续 |
| reassign | 重新派发 | failed/rejected → pending | 更换执行人 |
| cancel | 取消任务 | accepted/in_progress → cancelled | 主动取消 |
| withdraw | 撤回任务 | pending → cancelled | 撤回未接受的任务 |
| extend | 延期 | - | 延长截止日期 |
| remind | 催办 | - | 提醒执行人 |
