  case 'a': {
    const foo = 1;
    break;
  }
}

### 3.3 MEDIUM/LOW 级别问题

#### React Hooks 依赖项问题 (exhaustive-deps)
共 **30+ 处**，主要是 `useEffect` 和 `useCallback` 的依赖数组不完整。

**影响**: 可能导致 stale closure 问题，组件行为不符合预期。

**示例**:
```tsx
// 警告
useEffect(() => {
  refreshData();
}, []); // 缺少 refreshData 依赖

// 建议
useEffect(() => {
  refreshData();
}, [refreshData]);
```

#### Fast Refresh 警告
共 **8 处**，文件导出了常量/函数而非仅导出组件。

**影响**: 开发时热更新可能不生效。
