## 一、项目背景与目标

### 1.1 项目背景

人工管理模块是种植管理系统的重要组成部分，涵盖了从员工入职到离职的完整生命周期管理。当前模块存在以下问题：

1. **数据孤岛问题**：临时工和正式员工数据分离，各子模块数据无法共享
2. **硬编码严重**：HrApprovalDocuments、H rAttendance等页面存在大量硬编码数据
3. **业务流程断裂**：请假/加班申请与审批流程未完全打通
4. **组件重复**：批量编辑、导出、分页等组件在每个模块重复实现
5. **HR审批单功能缺失**：新增、编辑、查看按钮无实际功能

### 1.2 项目目标

本次优化的核心目标是：

1. **数据连通**：建立统一的员工主数据模型，实现各模块数据共享
2. **流程顺通**：梳理并打通从入职到离职的完整业务流程
3. **体验优化**：统一组件设计，提升用户体验
4. **业务闭环**：实现请假/加班/调岗/离职等业务的完整审批闭环

### 1.3 目标用户

| 用户角色 | 需求描述 |
|---------|---------|
| **普通员工** | 提交请假/加班申请、查看工资、查看考勤记录 |
| **班组长** | 查看组员考勤、审批组员申请、安排排班 |
| **人事专员** | 员工入职办理、合同管理、HR审批 |
| **人事经理** | 部门人事管理、薪资核算、报表分析 |
| **系统管理员** | 部门/岗位配置、权限管理、系统设置 |
| **财务人员** | 工资发放、社保公积金核算 |

```sql
-- 员工主表
CREATE TABLE m_worker (
    -- 主键和编码

    phone VARCHAR(20) NOT NULL COMMENT '联系电话',
    email VARCHAR(100) COMMENT '电子邮箱',
    gender ENUM('男','女') NOT NULL COMMENT '性别',
    birth_date DATE COMMENT '出生日期',
    nation VARCHAR(20) COMMENT '民族',
    native_place VARCHAR(100) COMMENT '籍贯',
    address VARCHAR(200) COMMENT '现住址',
    photo_url VARCHAR(200) COMMENT '照片URL',

    -- 紧急联系人
    emergency_contact VARCHAR(50) COMMENT '紧急联系人',
    emergency_phone VARCHAR(20) COMMENT '紧急联系电话',

    -- 组织架构
    dept_id VARCHAR(20) COMMENT '部门ID',
    position_id VARCHAR(20) COMMENT '岗位ID',
    team_id VARCHAR(20) COMMENT '班组ID',

    -- 入职信息
    worker_type ENUM('正式工','临时工','季节工','实习生') NOT NULL COMMENT '用工类型',
    entry_date DATE NOT NULL COMMENT '入职日期',
    probation_months INT COMMENT '试用期月数',
    probation_end_date DATE COMMENT '试用期结束日期',

    -- 薪资配置
    salary_type ENUM('月薪制','日薪制','时薪制','计件制') DEFAULT '月薪制' COMMENT '薪资类型',
    base_salary DECIMAL(10,2) COMMENT '基本工资',
    hourly_rate DECIMAL(10,2) COMMENT '时薪',
    daily_rate DECIMAL(10,2) COMMENT '日薪',
    position_salary DECIMAL(10,2) COMMENT '岗位工资',

    -- 社保公积金
    social_security_no VARCHAR(30) COMMENT '社保账号',
    housing_fund_no VARCHAR(30) COMMENT '公积金账号',
    social_security_base DECIMAL(10,2) COMMENT '社保缴纳基数',
    housing_fund_base DECIMAL(10,2) COMMENT '公积金缴纳基数',

    -- 银行信息
    bank_account VARCHAR(30) COMMENT '银行账号',
    bank_name VARCHAR(100) COMMENT '开户行',

    -- 技能和区域
    skill_tags JSON COMMENT '技能标签JSON数组',
    work_zones JSON COMMENT '工作区域JSON数组',

    -- 状态
    status ENUM('在职','离职','停薪留职','试用期','退休') DEFAULT '试用期' COMMENT '在职状态',
    leave_date DATE COMMENT '离职日期',
    leave_reason VARCHAR(200) COMMENT '离职原因',

    -- 系统字段
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by VARCHAR(50) COMMENT '创建人',
    deleted_at DATETIME COMMENT '删除时间',
    deleted_by VARCHAR(50) COMMENT '删除人',

    -- 外键
    INDEX idx_dept (dept_id),
    INDEX idx_position (position_id),
    INDEX idx_team (team_id),
    INDEX idx_status (status),
    INDEX idx_entry_date (entry_date),
    INDEX idx_id_card (id_card),
    CONSTRAINT fk_worker_dept FOREIGN KEY (dept_id) REFERENCES m_department(dept_id),
    CONSTRAINT fk_worker_position FOREIGN KEY (position_id) REFERENCES m_position(position_id),
    CONSTRAINT fk_worker_team FOREIGN KEY (team_id) REFERENCES m_team(team_id)
) COMMENT '员工主表';
```
