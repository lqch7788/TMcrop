# 人工管理模块与HR审批中心 - V2.0规划方案

## 一、项目概述

### 1.1 目标
对人工管理模块(23个子模块)与HR审批中心进行深度代码分析，制定完整的数据整理、流程梳理、数据流关联规划方案，实现所有页面的数据连通和业务流程闭环。

### 1.2 当前状态
- **人工管理模块**: 5个聚合页面 + 23个子模块，位于 `src/components/labor/`
- **HR审批中心**: 主页面(HrApproval.tsx) + 考勤单据页面(HrApprovalDocuments.tsx)
- **审批上下文**: ApprovalContext.tsx 全局状态管理
- **审批类型**: 4种(请假/加班/离职/招聘申请)，需扩展到10种

---

## 二、问题识别

### 2.1 数据孤岛问题
| 孤岛页面 | 问题描述 | 联动影响 |
|---------|---------|---------|
| LeavePage | 请假数据独立，不经过审批系统 | 考勤系统无法获取已批假数据 |
| OvertimePage | 加班数据独立，不经过审批系统 | 工资系统无法获取加班数据 |
| RecruitmentPage | 招聘申请独立，无审批流程 | 入职流程无法触发 |
| HrApprovalDocuments | 考勤单据独立数据源 | 与LeavePage/OvertimePage数据不同步 |

### 2.2 员工ID体系混乱
| 格式 | 来源 | 问题 |
|-----|------|-----|
| S001/S002 | LeavePage, OvertimePage | 不统一 |
| W001/W002 | 其他页面 | 不统一 |
| EMP001/EMP002 | 员工档案 | 标准格式 |

**解决方案**: 统一为 `EMP-YYYYMMDD-XXX` 格式

### 2.3 缺失的审批类型
需要新增6种审批类型:
1. 招聘申请审批
2. 入职办理审批
3. 考勤补录审批
4. 调薪申请审批
5. 合同续签审批
6. 工资预算审批

## 三、数据库表结构设计

### 3.1 核心员工表
```sql
CREATE TABLE hr_employee (
  id VARCHAR(50) PRIMARY KEY,           -- EMP-YYYYMMDD-XXX
  employee_code VARCHAR(20) UNIQUE,      -- 工号
  name VARCHAR(100) NOT NULL,           -- 姓名
  gender VARCHAR(10),                    -- 性别
  birth_date DATE,                      -- 出生日期
  id_card VARCHAR(18),                  -- 身份证号
  phone VARCHAR(20),                    -- 联系电话
  email VARCHAR(100),                   -- 邮箱
  department_id VARCHAR(50),           -- 部门ID
  position VARCHAR(100),                -- 职位
  employment_type VARCHAR(20),          --用工类型
```

```typescript
export enum ApprovalType {
  LEAVE = 'leave',                       // 请假申请

  // 调薪

}

export interface ApprovalStep {

  approverId: string;
  approverName: string;
  status: ApprovalStatus;

  actionTime?: string;
}
```

## 八、业务流程设计

### 8.1 请假-审批-考勤 闭环流程

```
1. 员工提交请假申请
   └─> 填写请假类型、日期、时长、原因
   └─> 选择审批人(部门经理)

2. 审批流程
   └─> 部门经理审批
   └─> 审批通过: 更新请假状态为approved
   └─> 审批拒绝: 更新请假状态为rejected,通知申请人

3. 考勤系统联动
   └─> 请假批准后,考勤记录自动标记为对应假期类型
   └─> 请假时长计入考勤统计
   └─> 请假扣减对应假期余额(如年假)

4. 数据归档
   └─> 请假记录归档到历史表
   └─> 更新员工假期余额
```

### 8.2 加班-审批-工资 闭环流程

```
1. 员工提交加班申请
   └─> 选择加班日期、开始时间、结束时间
   └─> 系统自动计算加班时长
   └─> 选择审批人(部门经理)

2. 加班规则校验
   └─> 工作日加班: >=2小时才算加班
   └─> 周末/节假日: 全天算加班
   └─> 超出法定加班时长上限(36小时/月)提示警告

3. 审批流程
   └─> 部门经理审批
   └─> 超出部门加班预算时,需HRD二次审批

4. 加班费计算
   └─> 工作日加班: 基本工资/21.75/8 * 1.5 * 加班小时数
   └─> 周末加班: 基本工资/21.75/8 * 2 * 加班小时数
   └─> 节假日加班: 基本工资/21.75/8 * 3 * 加班小时数

5. 工资系统联动
   └─> 加班批准后,加班费自动计入当月工资
   └─> 生成加班费明细
```

### 8.3 招聘-审批-入职-员工档案 闭环流程

```
1. 部门提交招聘申请
   └─> 填写岗位、人数、用工类型、薪资范围
   └─> 选择审批人(HR总监)

2. 审批流程
   └─> HR总监审批
   └─> 薪资超出预算时,需CEO审批

3. 招聘执行
   └─> 发布招聘信息
   └─> 收集简历
   └─> 面试安排
   └─> 录用决定

4. 入职办理(新审批类型)
   └─> 发起入职办理申请
   └─> 填写候选人信息、岗位、薪资
   └─> 审批流程: HR同事 -> HR经理

5. 员工档案创建
   └─> 入职批准后,自动创建员工档案
   └─> 分配工号(EMP-YYYYMMDD-XXX)
   └─> 初始化考勤规则
   └─> 创建工资账户

6. 试用期管理
   └─> 设置试用期时长
   └─> 试用期考核流程
   └─> 试用期转正审批
```

### 8.4 离职-审批-结算-关户 闭环流程

```
1. 员工提交离职申请
   └─> 选择离职类型(主动/被动)
   └─> 填写预计最后工作日
   └─> 填写离职原因和交接说明

2. 审批流程
   └─> 直属上级审批
   └─> 离职面谈(HRA)
   └─> 薪资结算确认

3. 离职交接
   └─> 工作交接清单
   └─> 物品归还
   └─> 账号权限关闭

4. 薪资结算
   └─> 计算最后月份工资
   └─> 未休年假折算
   └─> 离职补偿金(如有)
   └─> 扣除应扣款项

5. 账户关户
   └─> 考勤账户冻结
   └─> 门禁权限移除
   └─> 邮箱/系统账号停用
   └─> 员工状态改为inactive
```

### 8.5 考勤补录-审批-确认 流程

```
1. 员工提交考勤补录申请
   └─> 选择补录日期
   └─> 填写实际签到/签退时间
   └─> 选择补录原因
   └─> 上传证明材料(如外出记录)

2. 审批流程
   └─> 直属上级审批
   └─> 异常考勤超过3次/月时,需HR经理审批

3. 补录生效
   └─> 审批通过后,更新考勤记录
   └─> 重新计算当日工作时长
   └─> 更新考勤统计
```
