## 二、CRITICAL 问题（必须立即修复）

### 2.1 window.location.reload() 刷新页面

**文件**: `src/pages/farm/AgricultureRecordPage.tsx:215, 234`

```typescript
// 行 215
window.location.reload();

// 行 234
window.location.reload();
```

**问题**: 使用 `window.location.reload()` 会导致整个页面重新加载，用户状态丢失，体验较差。

**影响**: 用户在填写表单或操作过程中可能被意外刷新丢失数据。

**修复建议**:
```typescript
// 使用 React 状态管理来触发数据刷新，而非页面刷新
const [refreshKey, setRefreshKey] = useState(0);
const handleRefresh = () => setRefreshKey(prev => prev + 1);

// 在数据获取时使用 refreshKey 作为依赖
const { data } = useQuery({
  queryKey: ['agricultureRecords', refreshKey],
  queryFn: fetchRecords
});
```
