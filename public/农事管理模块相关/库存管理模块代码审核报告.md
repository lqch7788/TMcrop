## 二、CRITICAL 问题（必须立即修复）

### 2.1 unfreezeInventory 空字符串查询 bug

**文件**: `src/services/inventoryService.ts:529`

```typescript
// 问题代码
const query = status === '' ? {} : { status };
// 当 status 为空字符串时，查询所有状态，导致数据不匹配
```

**问题**: 当 `status` 为空字符串时，`unfreezeInventory` 会返回所有状态的记录，而不仅仅是"已冻结"的记录。

**影响**: 解冻操作可能获取到错误的数据，导致库存状态不一致。

**修复建议**:
```typescript
const query = status ? { status } : {};
```

## 三、HIGH 问题（应该修复）

### 3.1 乐观锁竞态条件

**文件**: `src/services/inventoryService.ts`

```typescript
// 读取当前版本
const current = await this.findById(instanceId);
// 计算新数量
const newQuantity = current.quantity + delta;
// 更新时未验证版本号
await this.update(instanceId, { quantity: newQuantity });
```

**问题**: 乐观锁检查和更新之间存在时间窗口，多个并发请求可能覆盖彼此的更新。

**修复建议**:
```typescript
const current = await this.findById(instanceId);
if (current.version !== expectedVersion) {
  throw new OptimisticLockError('版本冲突');
}
await this.update(instanceId, {
  quantity: newQuantity,
  version: current.version + 1
});
```

**问题**: JSON 解析失败时会抛出异常，导致程序崩溃。
