## 二、CRITICAL 问题（必须立即修复）

### 2.1 getInspectionStats 忽略 filters 参数

**文件**: `src/services/apiInspectionService.ts:195-208`

```typescript
export async function getInspectionStats(
  farmId: string,
  filters?: InspectionFilters
): Promise<InspectionStats> {
  // 问题：filters 参数被完全忽略
  // const queryParams = new URLSearchParams();
  // if (filters) { ... }  // 这些代码被注释掉了

  return apiClient.get<InspectionStats>('/inspections/stats', {
    params: { farmId }  // 只传了 farmId，没有 filters
  });
}
```

**问题**: `getInspectionStats` 函数接收 `filters` 参数但未使用，导致无法按条件筛选统计数据。

**影响**: 统计报表数据不准确，可能显示全量数据而非用户筛选的数据。

**修复建议**:
```typescript
export async function getInspectionStats(
  farmId: string,
  filters?: InspectionFilters
): Promise<InspectionStats> {
  const params: Record<string, string> = { farmId };

  if (filters) {
    if (filters.startDate) params.startDate = filters.startDate;
    if (filters.endDate) params.endDate = filters.endDate;
    if (filters.inspectionType) params.inspectionType = filters.inspectionType;
    if (filters.status) params.status = filters.status;
  }

  return apiClient.get<InspectionStats>('/inspections/stats', { params });
}
```
