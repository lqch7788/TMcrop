# 🔴 CRITICAL问题（共55+个）

## 1. 安全漏洞类（13个）

### [CRITICAL] 后端API完全无鉴权
- **文件**: `server/src/index.ts:50-55`
- **问题**: 所有API路由 `/api/*` 没有任何认证中间件
- **修复**: 实现JWT token验证或session认证中间件

### [CRITICAL] 前端权限控制被禁用
- **文件**: `src/hooks/usePermission.ts:271-277`
- **问题**: `can()` 函数直接返回 `true`
- **修复**: 恢复权限检查逻辑

### [CRITICAL] localStorage管理员标志可伪造
- **文件**: `src/hooks/usePermission.ts:78-89, 232-265`
- **问题**: 管理员判断依赖前端localStorage，可通过JS修改
- **修复**: 管理员状态必须由后端验证

### [CRITICAL] 硬编码密码123456
- **文件**: `src/pages/Login.tsx:27`
- **问题**: 密码验证是硬编码的 `123456`
- **修复**: 删除硬编码，实现真正的密码验证

### [CRITICAL] 密码明文存储
- **文件**: `server/src/db/seedData.ts:2280`
- **问题**: 用户密码以明文存储在数据库中
- **修复**: 使用bcrypt/argon2哈希算法

### [CRITICAL] 硬编码用户名绕过
- **文件**: `src/hooks/usePermission.ts:260-263`
- **问题**: `if (username === '陆启闯') return true`
- **修复**: 删除硬编码逻辑

### [CRITICAL] SQL注入漏洞
- **文件**: `server/src/routes/basicData.ts:1208`
- **问题**: `WHERE workflow_oid = '${workflowOid}'` 直接拼接
- **修复**: 使用参数化查询

### [CRITICAL] ORDER BY注入风险
- **文件**: `server/src/routes/authority.ts:33,187,469`
- **问题**: `ORDER BY ${sort} ${order}` 直接拼接
- **修复**: 使用白名单验证
