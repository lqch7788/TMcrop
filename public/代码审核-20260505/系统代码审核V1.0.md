## 🔴 CRITICAL 问题清单（共7个）

### 1. 【种植模块】EditModal 编辑后不保存数据
- **文件**: `src/components/farm/planting/modals/EditModal.tsx:38-41`
- **问题**: `handleSubmit` 只打印日志和关闭弹窗，**完全没有调用任何API保存修改**
- **影响**: 用户编辑的数据会丢失
- **修复**:
```typescript
const handleSubmit = async () => {
  try {
    await updatePlanting(record.id, formData);
    onSuccess?.();
    onClose();
  } catch (error) {
    console.error('更新失败:', error);
    alert('更新失败，请重试');
  }
};
```

### 2. 【种植模块】采收接口 404
- **文件**: `src/services/apiPlantingService.ts:99-105`
- **问题**: `harvestPlanting()` 调用 `/plantings/${id}/harvest`，但后端**完全没有这个路由**
- **影响**: 采收功能完全不可用
- **修复**: 在后端添加 `/plantings/:id/harvest` 路由，或修改前端使用通用 `updatePlanting` 接口

### 3. 【生产计划】创建计划未持久化到SQLite
- **文件**: `src/components/production/ProductionPage.tsx:166-219`
- **问题**: `handleSubmit` 创建新批次时只更新本地state，没有调用后端API写入SQLite
- **影响**: 页面刷新后新创建的计划会丢失
- **修复**: 创建生产计划时同时调用后端API

### 4. 【生产计划】每日/月度规划直接读取 localStorage
- **文件**:
  - `src/pages/DailyPlanningPage.tsx:197-206`
  - `src/pages/MonthlyPlanningPage.tsx:197-206`
  - `src/hooks/useDailyTaskPlanning.ts:245`
- **问题**: 多个页面直接读取 `yuanxingtu_batches`，而不是从后端API获取
- **影响**: 与使用后端API的 `PlanSummary.tsx` 数据不一致
- **修复**: 创建统一的批次数据获取hook，优先从后端API获取

### 5. 【仓储】入库/出库操作不调用后端API
- **文件**: `src/components/warehouse/WarehouseMaterialsPage.tsx:659-667`
- **问题**: `handleSaveNewInbound` 只将数据放入React state，没有持久化到后端
- **影响**: 刷新页面后数据丢失
- **修复**: 为所有CRUD操作创建后端API，前端调用对应接口

### 6. 【仓储】硬编码Mock数据未迁移
- **文件**: `src/components/warehouse/WarehouseMaterialsPage.tsx:185-345`
- **问题**: 页面硬编码了13条物料数据和12条入库记录
- **影响**: 页面刷新后数据丢失，无法持久化
- **修复**: 创建后端API接口，移除硬编码数据

### 7. 【采收】双数据源配置导致不一致
- **文件**: `src/services/apiHarvestService.ts:6-10`
- **问题**: 根据 `USE_API` 环境变量在API模式和localStorage模式之间切换
- **影响**: 环境配置不一致或后端不可用时，数据读写到不同存储
- **修复**: 移除localStorage回退机制，强制使用API
