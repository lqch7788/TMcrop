# 种植管理系统迁移规划方案 V4.0

**文档版本：** V4.0
**编制日期：** 2026-04-26
**目标：** 用V1.1系统替代旧管理模块，保留旧功能并进行功能增强

---

## 一、项目背景与目标

### 1.1 背景
- **旧系统** (D:\iAGS\new): 农业物联网平台，使用 EJS + jQuery EasyUI，有6个管理页面
- **新系统** (V1.1): 基于 React + TypeScript + Ant Design 的现代农业管理系统
- **目标**: 用 V1.1 替代旧管理模块，保留旧功能并进行功能增强

### 1.2 旧系统6个管理页面
| 页面 | 功能 | V1.1现状 | 规划 |
|-----|------|---------|------|
| 种源管理 | 种子/种苗采购入库 | 缺失 | **新增** |
| 育苗管理 | 育苗批次和成苗率管理 | 缺失 | **新增** |
| 种植管理 | 区域种植记录管理 | 缺失 | **新增** |
| 施肥管理 | 施肥记录管理 | 已有农事管理 | 替代 |
| 产量管理 | 产量记录管理 | 已有采收入库 | 替代 |
| 采购商管理 | 供应商管理 | 已有供应商管理 | 替代 |

---

## 二、系统现状分析

### 2.1 旧系统核心数据结构

**种源管理**:
- seedCode (批号), cropName (作物), seedType (类型), supplierName (供应商)
- purchaseDate, quantity, unit, availableCount, pictures

**育苗管理**:
- seedlingCode (育苗批号), sourceCode (关联种源)
- cropName, seedlingType, siteName, startDate, endDate
- initialCount, survivalCount, survivalRate, lossRate, pictures

**种植管理**:
- plantCode (种植批号), seedlingCode (关联育苗)
- cropName, areaName, plantingCount, plantingDate
- soilPH, soilEC, isHarvest, harvestDate, lossRate, pictures

### 2.2 V1.1系统架构

```
技术栈: React 18.3 + TypeScript + Vite + Ant Design + Tailwind CSS
模式: 组件化开发 (types/data/components/pages)
路由: App.tsx
菜单: Sidebar.tsx
```

---

## 三、融合原则

| 原则 | 说明 |
|------|------|
| **功能完整保留** | 旧系统所有功能必须完整保留，一一对应迁移 |
| **组件式开发** | 所有数据从 types/ 和 mockData/ 导入，禁止硬编码 |
| **数据可选项** | 数据关联为可选项，非强制，可独立操作 |
| **权限暂不实现** | 默认所有用户可用，不做权限控制 |
| **原型演示优先** | 暂不涉及数据库对接，聚焦前端原型 |

---

## 四、关键决策（已确认）

| 项目 | 决策 |
|------|------|
| 数据关联 | 可设定关联，非强制，可独立操作 |
| 二维码 | 保留，前端生成（qrcode库） |
| 数据库 | 暂不考虑，原型演示阶段 |
| 权限 | 默认开放，不做控制 |
| 开发顺序 | 种源管理 → 育苗管理 → 种植管理 |
| UI风格 | 必须与农事管理模块保持一致 |

### 8.1 类型定义文件

创建 `src/types/crop.ts`：

```typescript
// ========== 枚举定义 ==========
export enum SourceType {
  SEEDLING = 'seedling',
  SEED = 'seed'
}

export enum SeedType {
  SEED = 'seed',
  SEEDLING = 'seedling'
}

export enum SeedlingStatus {
  IN_PROGRESS = 'in_progress',
  TRANSPLANT_READY = 'transplant_ready',
  COMPLETED = 'completed',
  ABNORMAL = 'abnormal'
}

export enum PlantingStatus {
  PLANTED = 'planted',
  GROWING = 'growing',
  HARVESTED = 'harvested',
  CANCELLED = 'cancelled'
}

export enum PrintTemplate {
  SMALL = 'small',
  LARGE = 'large'
}

// ========== 种源类型 ==========
export interface SeedSource {
  id: string;
  seedCode: string;           // 种源批号
  sourceType: SourceType;      // 来源类型
  cropCategory: string;        // 作物种类
  cropName: string;           // 作物名称
  cropVariety: string;        // 作物品种
  supplierId: string;         // 供应商ID
  supplierName: string;        // 供应商名称
  purchaseDate: string;       // 购买日期
  quantity: number;           // 包装数量
  unit: string;               // 单位
  unitPrice: number;          // 单价
  totalAmount: number;        // 总金额
  initialCount: number;       // 初始数量
  availableCount: number;     // 可用数量
  pictures: string[];         // 图片列表（Base64）
  remarks?: string;           // 备注
  status: 'sufficient' | 'low' | 'depleted';
  traceabilityCode?: string;   // 溯源码
  printCount: number;         // 打印次数
  createBy: string;
  createTime: string;
  updateTime: string;
}

// ========== 每日记录类型 ==========
export interface DailyRecord {
  id: string;
  seedlingId: string;
  recordDate: string;
  temperature?: number;
  humidity?: number;
  watering: boolean;
  abnormality?: string;
  remarks?: string;
}

// ========== 育苗类型 ==========
export interface Seedling {
  id: string;
  seedlingCode: string;        // 育苗批号
  sourceId: string;           // 关联种源ID
  sourceCode: string;         // 关联种源批号
  cropName: string;           // 作物名称
  cropVariety: string;        // 作物品种
  seedlingType: string;       // 育苗方式
  siteId: string;             // 场地ID
  siteName: string;           // 场地名称
  startDate: string;          // 育苗开始日期
  expectedEndDate?: string;
  endDate?: string;           // 实际成苗日期
  initialCount: number;       // 初始数量
  survivalCount: number;      // 成活数量
  plantedCount: number;       // 已定植数量
  survivalRate: number;        // 成苗率（计算）
  lossCount: number;          // 损耗数量
  lossRate: number;           // 损耗率（计算）
  isFinished: boolean;        // 是否完成
  status: SeedlingStatus;
  dailyRecords: DailyRecord[];
  pictures: string[];
  qualityGrade?: string;
  printCount: number;
  remarks?: string;
  createBy: string;
  createTime: string;
  updateTime: string;
}

// ========== 种植类型 ==========
export interface Planting {
  id: string;
  plantCode: string;          // 种植批号
  sourceType: SourceType;
  sourceId: string;
  sourceCode: string;         // 来源批号
  cropName: string;
  cropVariety: string;
  areaId: string;
  areaName: string;
  rootName: string;
  plantingCount: number;
  plantingDate: string;
  soilPH?: number;
  soilEC?: number;
  transplantCount?: number;
  transplantDate?: string;
  isHarvest: boolean;
  harvestDate?: string;
  attritionRate: number;
  printCount: number;
  traceabilityCode: string;
  pictures: string[];
  remarks?: string;
  status: PlantingStatus;
  createBy: string;
  createTime: string;
  updateTime: string;

// ========== 筛选状态类型 ==========
export interface SeedSourceFilters {
  cropName: string;

  sourceType: string;
  supplierName: string;

export interface PlantingFilters {
```

## 十一、技术要点

### 11.1 组件式开发模式
- 所有数据从 `types/` 和 `data/` 导入，禁止硬编码
- 枚举值、状态值必须从类型定义导入

### 11.2 UI规范遵循
- **必须与农事管理模块（Harvest/AgriCulture）保持完全一致的UI风格**
- 表头样式：`bg-emerald-600` 绿色背景 + 白色文字
- 分页组件：统一使用项目中已封装的分页样式

### 11.3 UI设计规范（必须遵循）

#### 11.3.1 统计卡片样式
```
- 背景：bg-white rounded-xl p-4 shadow-sm border border-gray-100
- 图标容器：w-10 h-10 rounded-lg + 主题色
- 数值：text-2xl font-bold text-gray-900
- 标签：text-sm text-gray-500
```

#### 11.3.2 筛选工具栏样式
```
- 容器：bg-[#F2F6FA] rounded-xl p-4 shadow-sm
- 标签：text-sm font-medium text-gray-700 mb-1
- 输入框：w-full h-10 px-3 border border-gray-200 rounded-lg text-sm
- 输入框focus：focus:outline-none focus:border-emerald-500
- 选择框：同输入框样式
```

#### 11.3.3 按钮样式
| 按钮类型 | 样式 | 说明 |
|---------|------|------|
| 主按钮（搜索/新增） | `bg-emerald-600 text-white hover:bg-emerald-700` | 绿色主按钮 |
| 次按钮（重置/取消） | `bg-gray-200 text-gray-700 hover:bg-gray-300` | 灰色次按钮 |
| 危险按钮（删除） | `bg-red-500 text-white hover:bg-red-600` | 红色警告按钮 |
| 图标按钮 | `p-1 text-red-500 hover:bg-red-50 rounded` | 操作列图标 |

#### 11.3.4 弹窗样式
```
- 使用 UnifiedModal 组件
- 尺寸：default/xl/xxl 根据内容选择
- 标题：text-base font-semibold text-gray-900
```

#### 11.3.5 表单样式
```
- 标签：text-sm font-medium text-gray-900 mb-1
- 输入框：w-full px-3 py-2 border border-gray-400 rounded-lg text-sm
- 输入框focus：focus:outline-none focus:ring-2 focus:ring-emerald-500
- 错误提示：text-red-500 text-xs mt-1
```

#### 11.3.6 表格样式
```
- 表头背景：bg-emerald-600
- 表头文字：text-sm font-semibold text-white
- 行hover：hover:bg-gray-50
- 斑马纹：divide-y divide-gray-200
```

#### 11.3.7 颜色系统
```
主色调：emerald（绿色）
- emerald-500：次要强调
- emerald-600：主按钮、表格表头
- emerald-700：按钮hover
- emerald-50：信息背景高亮

中性色：gray
- gray-100：卡片背景
- gray-200：次要按钮
- gray-400：边框
- gray-500：次要文字
- gray-700：主要文字
- gray-900：标题文字
```
