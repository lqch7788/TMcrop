# 作物管理模块功能与数据流转说明

> 文档版本：V1.0
> 更新日期：2026-04-26
> 状态：已完成

---

## 一、模块概述

作物管理模块是整个农业管理系统的核心模块，实现了从**种源入库 → 育苗 → 种植 → 采收入库 → 订单销售**的完整生命周期追踪。系统通过统一的**作物实例编码（CropInstance）**贯穿各个环节，确保数据关联可追溯。

### 1.1 模块入口

```
侧边栏 → 作物管理
├── 种源管理      /crop/seed-source
├── 育苗管理      /crop/seedling
├── 种植管理      /crop/planting
├── 采收入库      /crop/harvest
├── 订单管理      /crop/order
└── 实例追溯      /crop/instance
```

---

## 二、核心概念

### 2.1 作物实例编码规则

作物实例编码是整个追踪系统的核心，每个作物批次拥有唯一的18位编码：

```
编码结构：品种编码(9位) + 年月日(6位) + 流水号(3位)
示例：PD0301000100240426001
```

| 段落 | 位置 | 说明 | 示例 |
|------|------|------|------|
| 大类代码 | 1-2位 | 产品大类 | PD=蔬菜, FR=水果 |
| 类型代码 | 3-4位 | 产品类型 | 03=茄果类 |
| 品种代码 | 5-6位 | 具体品种 | 01=番茄 |
| 流水号 | 7-9位 | 当日序号 | 001 |
| 年月日 | 10-15位 | 入库日期 | 240426 |
| 批次号 | 16-18位 | 批内序号 | 001 |

### 2.2 作物来源类型（SourceOrigin）

系统支持多种作物来源方式：

| 来源类型 | 代码 | 说明 |
|----------|------|------|
| 内部种源 | internal_seed | 自行留种繁殖 |
| 外部采购 | external_purchase | 从供应商采购种子/种苗 |
| 组培苗 | tissue_culture | 植物组织培养 |
| 嫁接苗 | grafting | 嫁接繁殖 |
| 分株繁殖 | seedling_split | 分株繁殖 |
| 扦插繁殖 | cutting | 扦插繁殖 |
| 直接育苗 | direct_seedling | 自繁直接育苗 |
| 直接种植 | direct_planting | 外购苗直接定植 |
| 外购成品 | external_harvest | 外购成品入库 |

## 三、功能模块详解

### 3.1 种源管理

**路由**：`/crop/seed-source`
**功能**：管理作物种子/种苗的来源信息

#### 3.1.1 核心功能

| 功能 | 说明 |
|------|------|
| 新增种源 | 记录种源批次信息，自动生成种源批号 |
| 编辑种源 | 修改种源信息 |
| 删除种源 | 删除种源记录 |
| 库存管理 | 跟踪可用数量，库存不足时预警 |
| 打印标签 | 打印溯源码标签 |
| 筛选查询 | 按作物类别、名称、供应商等条件筛选 |

#### 3.1.2 数据结构

```typescript
interface SeedSource {
  id: string;                    // 唯一ID
  seedCode: string;             // 种源批号，如 ZZ20260426001
  sourceType: SourceType;       // SEED=种子, SEEDLING=种苗
  cropCategory: string;          // 作物类别，如"茄果类"
  cropName: string;             // 作物名称，如"番茄"
  cropVariety: string;          // 品种，如"红果番茄"
  cropCode: string;             // 作物编码，9位
  supplierId: string;           // 供应商ID
  supplierName: string;         // 供应商名称
  purchaseDate: string;         // 采购日期
  quantity: number;             // 采购数量（如：50袋）
  unit: string;                // 单位（如：袋、株）
  unitPrice: number;           // 单价
  totalAmount: number;         // 总金额
  initialCount: number;        // 初始数量（粒/株）
  availableCount: number;      // 可用数量
  status: StockStatus;         // SUFFICIENT/LOW/DEPLETED
  traceabilityCode: string;    // 溯源码
  instanceId: string;          // 关联的作物实例ID（新建时自动生成）
}
```

#### 3.1.3 操作流程

```
新增种源流程：

1. 点击【新增种源】按钮
2. 填写表单：
   - 选择作物类型（大类）
   - 选择作物名称
   - 选择品种
   - 选择种源类型（种子/种苗）
   - 选择供应商
   - 填写采购日期
   - 填写采购数量和单位
   - 填写单价（自动计算总金额）
   - 上传图片（可选）
   - 填写备注（可选）
3. 点击【保存】
4. 系统自动：
   - 生成种源批号（ZZ + 日期 + 流水号）
   - 生成作物编码（品种编码规则）
   - 创建作物实例（CropInstance）
   - 建立种源与实例的关联
```

#### 3.1.4 数量计算规则

```
initialCount = quantity × 1000（假设每袋1000粒/株）
availableCount = initialCount（新入库时等于初始数量）

当 availableCount 发生变化时：
- = 0 → status = DEPLETED（耗尽）
- < initialCount × 0.2 → status = LOW（不足）
- ≥ initialCount × 0.2 → status = SUFFICIENT（充足）
```

### 3.2 育苗管理

**路由**：`/crop/seedling`
**功能**：记录育苗过程，包括播种、发芽、生长、炼苗等阶段

#### 3.2.1 核心功能

| 功能 | 说明 |
|------|------|
| 新增育苗 | 从种源创建育苗记录 |
| 每日记录 | 记录温度、湿度、浇水等日常数据 |
| 状态更新 | 更新育苗进度和状态 |
| 定植操作 | 将成苗定植到种植环节 |
| 删除育苗 | 删除育苗记录 |
| 打印标签 | 打印溯源码标签 |

#### 3.2.2 育苗状态（SeedlingStatus）

| 状态 | 代码 | 说明 |
|------|------|------|
| 进行中 | IN_PROGRESS | 育苗正在进行 |
| 待定植 | TRANSPLANT_READY | 已成苗，等待定植 |
| 已完成 | COMPLETED | 全部定植完成 |
| 异常 | ABNORMAL | 育苗出现异常 |

#### 3.2.3 数据结构

```typescript
interface Seedling {
  id: string;                    // 唯一ID
  seedlingCode: string;          // 育苗批号，如 YM20260426001
  sourceId: string;             // 关联种源ID
  sourceCode: string;           // 关联种源批号
  cropName: string;             // 作物名称
  cropVariety: string;          // 品种
  cropCode: string;             // 作物编码
  seedlingType: string;         // 育苗方式（穴盘育苗/直播育苗/组培等）
  siteId: string;               // 场地ID
  siteName: string;             // 场地名称
  startDate: string;            // 开始日期
  expectedEndDate: string;      // 预计结束日期
  endDate: string;             // 实际结束日期
  initialCount: number;         // 初始数量
  survivalCount: number;        // 成活数量
  plantedCount: number;         // 已定植数量
  survivalRate: number;         // 成苗率（%）
  lossCount: number;            // 损耗数量
  lossRate: number;             // 损耗率（%）
  status: SeedlingStatus;       // 状态
  dailyRecords: DailyRecord[];  // 每日记录
  instanceId: string;           // 关联的作物实例ID
}
```

#### 3.2.4 操作流程

```
新增育苗流程：

1. 点击【新增育苗】按钮
2. 选择关联的种源批次（自动填充作物信息）
3. 填写表单：
   - 确认作物名称（自动来自种源）
   - 确认品种（自动来自种源）
   - 选择育苗方式
   - 选择温室场地
   - 填写开始日期
   - 填写预计结束日期
   - 填写初始数量
   - 上传图片（可选）
   - 填写备注（可选）
4. 点击【保存】
5. 系统自动：
   - 生成育苗批号
   - 扣减种源可用数量
   - 更新作物实例状态为"育苗中"

每日记录流程：

1. 在育苗列表中点击【每日记录】按钮
2. 选择要记录的日期
3. 填写当日数据：
   - 温度（℃）
   - 湿度（%）
   - 是否浇水
   - 异常情况（可选）
   - 备注（可选）
4. 点击【保存】

定植操作流程：

1. 在育苗列表中找到"待定植"状态的育苗
2. 点击【定植】按钮
3. 系统跳转到种植管理页面，自动填充：
   - 来源类型（来自育苗）
   - 作物名称
   - 品种
   - 来源批号
4. 填写种植信息并保存
5. 系统自动：
   - 更新育苗的已定植数量
   - 判断是否需要更新育苗状态
```

### 3.3 种植管理

**路由**：`/crop/planting`
**功能**：记录定植/移栽信息，包括种植位置、数量、成活率等

#### 3.3.1 核心功能

| 功能 | 说明 |
|------|------|
| 新增种植 | 从种源或育苗创建种植记录 |
| 移栽操作 | 记录移栽信息 |
| 采收登记 | 标记已采收 |
| 删除种植 | 删除种植记录 |
| 打印标签 | 打印溯源码标签 |

#### 3.3.2 种植状态（PlantingStatus）

| 状态 | 代码 | 说明 |
|------|------|------|
| 已定植 | PLANTED | 刚完成定植 |
| 生长期 | GROWING | 进入生长期 |
| 已采收 | HARVESTED | 已完成采收 |
| 已取消 | CANCELLED | 种植取消 |

#### 3.3.3 数据结构

```typescript
interface Planting {
  id: string;                    // 唯一ID
  plantCode: string;             // 种植批号
  sourceType: SourceType;        // 来源类型（SEED/SEEDLING）
  sourceId: string;             // 来源ID（种源或育苗ID）
  sourceCode: string;            // 来源批号
  cropName: string;             // 作物名称
  cropVariety: string;          // 品种
  cropCode: string;             // 作物编码
  areaId: string;               // 区域ID
  areaName: string;              // 区域名称
  rootName: string;             // 大棚/根区名称
  plantingCount: number;        // 种植数量
  plantingDate: string;         // 种植日期
  soilPH?: number;             // 土壤PH值
  soilEC?: number;             // 土壤EC值
  transplantCount?: number;     // 移栽数量
  transplantDate?: string;      // 移栽日期
  isHarvest: boolean;           // 是否已采收
  harvestDate?: string;         // 采收日期
  attritionRate: number;        // 损耗率（%）
  traceabilityCode: string;     // 溯源码
  status: PlantingStatus;       // 状态
  instanceId: string;          // 关联的作物实例ID
}
```

#### 3.3.4 操作流程

```
新增种植流程（从育苗定植）：

1. 在育苗管理中点击【定植】
2. 系统跳转到种植管理新增页面
3. 确认/填写表单：
   - 来源类型：种苗
   - 选择育苗批次（自动填充）
   - 作物名称（自动来自育苗）
   - 品种（自动来自育苗）
   - 选择种植区域
   - 填写种植数量
   - 填写种植日期
   - 填写土壤PH值（可选）
   - 填写土壤EC值（可选）
   - 上传图片（可选）
   - 填写备注（可选）
4. 点击【保存】
5. 系统自动：
   - 生成种植批号
   - 生成溯源码
   - 更新作物实例的已定植数量
   - 更新作物实例状态为"已定植"或"生长期"

采收登记流程：

1. 在种植列表中找到目标种植记录
2. 点击【采收】按钮
3. 填写采收信息：
   - 采收日期
   - 损耗率（可选，系统自动计算）
4. 点击【确认】
5. 系统自动：
   - 更新种植状态为"已采收"
   - 记录采收日期
   - 更新作物实例状态为"已采收"
```

### 4.2 数量变化规则

```
种源入库：
  initialCount = 采购数量 × 1000
  availableCount = initialCount

育苗创建：
  扣减种源 availableCount -= 育苗数量
  如 availableCount < 0，则提示"种源可用数量不足"

定植操作：
  扣减种源/育苗可用数量
  更新 CropInstance.plantedQuantity += 定植数量
  CropInstance.status = 'planted' 或 'growing'

采收入库：
  更新 CropInstance.harvestedQuantity += 采收数量
  CropInstance.currentQuantity -= 采收数量
  CropInstance.status = 'harvested'（当 currentQuantity = 0 时）
```

### 4.3 编码生成规则

| 编码类型 | 生成规则 | 示例 |
|----------|----------|------|
| 种源批号 | `ZZ` + 日期 + `-` + 流水号 | ZZ20260426-001 |
| 育苗批号 | `YM` + 年月日 + `-` + 流水号 | YM20260426-001 |
| 种植批号 | 来源批号 + `-` + 日期 | ZZ20260426-001-20260301 |
| 采收单号 | `HS` + 年月日 + 流水号 | HS20260426001 |
| 订单编号 | `DD` + 年月日 + 流水号 | DD20260426001 |
| 作物编码 | 大类+类型+品种+流水号 | PD03010001 |
| 实例编码 | 作物编码(9位)+年月日(6位)+流水号(3位) | PD0301000100240426001 |
| 溯源码 | `TR` + 日期 + 作物名前2字 | TR20260426番茄 |
