## 二、逐项差距分析

### 2.1 架构设计 ❌ 未达标

#### 手册标准
- **Feature-Sliced Design**: 按功能模块组织（features/、shared/）
- **单一职责**: 组件 < 300 行，函数 < 50 行
- **分层架构**: Controller → Service → Repository → Database

#### 当前问题

| 问题 | 现状 | 标准 | 差距 |
|------|------|------|------|
| **组件过大** | 生产计划 1100 行、技术方案 1768 行、采购计划 2036 行 | < 300 行 | ❌ 超标 3-7 倍 |
| **函数过长** | `loadProductionData` ~50 行、`handleCreateSubmit` ~30-50 行 | < 50 行 | ⚠️ 边界 |
| **模块边界模糊** | 页面组件直接调 API、管理状态、渲染 UI、处理导出 | 职责分离 | ❌ 混合职责 |
| **重复代码** | 三个页面都有独立的导出逻辑、批量操作逻辑、Modal 管理 | 提取复用 | ❌ 大量重复 |
| **没有 Service 层** | 前端直接 `apiClient.get/post/put/delete` | 封装 Service | ⚠️ 勉强可用 |

#### 问题代码示例
```typescript

  // 直接在这里处理导出
  const handleDoExport = async () => { ... };
  
  // 直接在这里处理删除
  const handleDeleteConfirm = async () => { ... };
  
  return (
    <div>
      {/* 300+ 行 JSX */}
    </div>
  );
}
```

### 2.2 代码质量 ⚠️ 部分达标

#### 手册标准
- ESLint 开启所有推荐规则
- Prettier 格式化
- 无 `any` 类型
- 命名清晰有意义
- 注释合理（复杂逻辑有说明）

#### 当前问题

| 问题 | 现状 | 标准 | 差距 |
|------|------|------|------|
| **ESLint 关闭关键规则** | `no-unused-vars: off`、`no-explicit-any: off` | 必须开启 | 🔴 严重 |
| **TypeScript 非严格模式** | `strict: false`、`noImplicitAny: false` | `strict: true` | 🔴 严重 |
| **硬编码数据** | `cropBatches`、`cropTypes`、`plantingModes` 等 mockData | 全部 API 驱动 | ⚠️ 存在降级 |
| **注释过多** | 大量中文注释解释 obvious 代码 | 自解释代码 | 🟡 轻微 |
| **命名不一致** | `batchCode` vs `planCode`、`greenhouseName` vs `greenhouseId` | 统一规范 | 🟡 轻微 |

#### 问题配置
```javascript
// eslint.config.js
rules: {
  'react-hooks': reactHooks,
  'react-refresh': reactRefresh,
  // ❌ 关闭了关键规则
  '@typescript-eslint/no-unused-vars': 'off',
  '@typescript-eslint/no-explicit-any': 'off',
}
```

```json
// tsconfig.app.json
{
  "strict": false,
  "noImplicitAny": false,
  "noImplicitReturns": false,
  "noImplicitThis": false
  // ❌ 严格模式全部关闭
}
```

### 2.3 测试覆盖 ❌ 未达标

#### 手册标准
- 单元测试覆盖率 > 80%
- 集成测试关键场景
- CI/CD 自动化测试
- `npm test` / `pnpm test:unit` 脚本

#### 当前问题

| 问题 | 现状 | 标准 | 差距 |
|------|------|------|------|
| **无测试脚本** | `package.json` 无 `test` 脚本 | 必须有 | 🔴 严重 |
| **测试文件极少** | 仅 6 个测试文件（全部测 Service 层） | 全栈覆盖 | 🔴 严重 |
| **无组件测试** | 0 个 React 组件测试 | 必须覆盖 | 🔴 严重 |
| **无 API 测试** | 0 个后端路由/集成测试 | 必须覆盖 | 🔴 严重 |
| **无 CI/CD** | 无 `.github/workflows` | GitHub Actions | 🔴 严重 |

#### 当前测试文件
```
src/__tests__/
├── harvestService.test.ts
├── productionPlanService.test.ts
├── seedSourceService.test.ts
├── inventoryV3.test.ts

```

### 2.4 安全实践 ❌ 未达标

#### 手册标准
- 输入验证（zod / joi）
- SQL 注入防护（参数化查询）
- XSS 防护（DOMPurify）
- CSRF 防护
- 速率限制
- 权限控制（RBAC）

#### 当前问题

| 问题 | 现状 | 标准 | 差距 |
|------|------|------|------|
| **权限控制已取消** | `// 权限控制 - 已取消，所有人可使用所有功能` | RBAC 权限 | 🔴 严重 |
| **无输入验证** | 前端表单无 schema 验证、后端无 zod/joi | 必须验证 | 🔴 严重 |
| **无 XSS 防护** | `dangerouslySetInnerHTML` 未检查、无 DOMPurify | 必须消毒 | 🔴 严重 |
| **后端 SQL 注入风险** | 字符串拼接 SQL：`sql += ' AND status = ?'` | 参数化查询 | ⚠️ 部分防护 |
| **无速率限制** | 后端无 express-rate-limit | 必须限制 | 🟡 中等 |
| **无 CSRF 防护** | 无 csurf 中间件 | 必须防护 | 🟡 中等 |
| **敏感信息硬编码** | `localStorage.getItem('username') || '陆启闯'` | 环境变量 | 🟡 中等 |

#### 问题代码
```typescript
// ProductionPage.tsx
// ❌ 权限控制已取消
const canCreate = true;
const canEdit = true;
const canDelete = true;
const canExport = true;

// PurchasePlanPage.tsx
// ❌ 无输入验证，直接提交
const handleCreateSubmit = async () => {
  const result = await apiClient.post('/purchase-plans', planData);
};

// server/src/routes/*.ts
// ⚠️ SQL 部分参数化但未完全防护
let sql = 'SELECT * FROM purchase_plans WHERE 1=1';
if (status) sql += ' AND status = ?';  // ← 参数化
if (keyword) sql += ' AND (field LIKE ?)';  // ← 参数化
// 但动态构建 SQL 仍有注入风险
```

### 2.5 性能优化 ⚠️ 部分达标

#### 手册标准
- 虚拟滚动（>100 条数据）
- 代码分割（Code Splitting）
- 图片优化/懒加载
- 缓存策略（Redis / 浏览器缓存）
- 数据库查询优化（避免 N+1）

#### 当前问题

| 问题 | 现状 | 标准 | 差距 |
|------|------|------|------|
| **无虚拟滚动** | 表格直接渲染全部数据 | react-window / tanstack-virtual | 🔴 严重 |
| **无代码分割** | 所有页面一次性加载 | React.lazy + Suspense | 🟡 中等 |
| **无图片优化** | 未使用 Next.js Image 组件 | 懒加载 + 响应式 | 🟡 中等 |
| **后端缓存** | 无 Redis / 无内存缓存 | 缓存层 | 🟡 中等 |
| **数据库查询** | 单次查询、分页已有 | 基本可用 | ✅ 达标 |

### 2.7 Prompt 工程 ⚠️ 部分达标

## 三、后端差距分析

### 3.1 后端架构

| 维度 | 手册标准 | 当前状态 | 差距 |
|------|---------|---------|------|
| **分层架构** | Controller → Service → Repository | Router → 直接操作 db.run() | ⚠️ 缺少 Service/Repository 层 |
| **类型安全** | TypeScript 严格模式 + DTO 验证 | 无 zod/joi 验证、any 较多 | 🔴 严重 |
| **错误处理** | 统一错误类（AppError / NotFoundError） | 每个路由 try/catch 重复 | 🟡 重复代码 |
| **日志记录** | 结构化日志（winston / pino） | console.error | 🔴 严重 |

### 3.2 后端安全

| 维度 | 手册标准 | 当前状态 | 差距 |
|------|---------|---------|------|
| **认证中间件** | JWT + Passport / Auth0 | 无认证中间件 | 🔴 严重 |
| **输入验证** | zod schema 验证 req.body | 无验证 | 🔴 严重 |
| **速率限制** | express-rate-limit | 无 | 🔴 严重 |
| **CORS** | 白名单配置 | 有 cors.ts 但配置宽松 | ⚠️ 部分 |
| **SQL 注入** | ORM / 完全参数化 | 字符串拼接 + 部分参数化 | ⚠️ 风险 |

## 四、优先修复清单

### 🔴 P0 — 必须立即修复（阻塞上线）

1. **开启 TypeScript 严格模式**
   ```json
   // tsconfig.app.json
   "strict": true,
   "noImplicitAny": true,
   "noImplicitReturns": true
   ```

2. **开启 ESLint 关键规则**
   ```javascript
   // eslint.config.js
   '@typescript-eslint/no-unused-vars': 'warn',
   '@typescript-eslint/no-explicit-any': 'error',
   ```

3. **恢复权限控制**
   ```typescript
   const { can } = useAuthPermission();
   const canDelete = can('production:delete');
   ```

4. **拆分巨型组件**
   - ProductionPage.tsx → 拆分为 `hooks/useProductionPlans.ts` + `components/ProductionTable.tsx` + `modals/*.tsx`
   - TechSolutionPage.tsx → 1768 行 → 拆分为 < 300 行组件
   - PurchasePlanPage.tsx → 2036 行 → 拆分为 < 300 行组件

5. **添加输入验证（前端 + 后端）**
   ```typescript
   import { z } from 'zod';
   const CreatePlanSchema = z.object({
     batchCode: z.string().min(1),
     targetQuantity: z.number().positive(),
   });
   ```

### 🔴 P1 — 高优先级（1-2周内修复）

6. **添加测试体系**
   - 安装 vitest + @testing-library/react
   - 添加 `npm test` 脚本
   - 为核心 Service 层添加单元测试
   - 为关键页面添加组件测试

7. **添加 GitHub Actions CI/CD**
   ```yaml
   # .github/workflows/ci.yml
   - lint
   - type-check
   - build
   - test
   ```

8. **后端添加认证中间件**
   ```typescript
   // middleware/auth.ts
   export function requireAuth(req, res, next) {
     const token = req.headers.authorization;
     if (!token) return res.status(401).json({ error: 'Unauthorized' });
     // verify JWT...
   }
   ```

9. **添加速率限制**
   ```typescript
   import rateLimit from 'express-rate-limit';
   app.use('/api/', rateLimit({ windowMs: 15 * 60 * 1000, max: 100 }));
   ```

10. **添加 Docker 支持**
    ```dockerfile
    # Dockerfile
    FROM node:20-alpine
    WORKDIR /app
    COPY package*.json ./
    RUN npm install
    COPY . .
    RUN npm run build
    CMD ["npm", "run", "dev"]
    ```

### 🟡 P2 — 中优先级（1个月内修复）

11. **虚拟滚动优化大表格**
    ```typescript

    ```

12. **代码分割**
    ```typescript

    ```

13. **后端添加 Service 层**
