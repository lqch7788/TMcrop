## 一、项目背景

### 1.1 旧系统现状

旧系统 `D:\iAGS\new` 中包含完整的种植管理模块，共6个页面：

| 页面 | 文件名 | 核心功能 |
|------|--------|---------|
| 种源管理 | provenanceManagement.ejs | 种子/种苗采购入库、查询、CRUD |
| 育苗管理 | seedlingManagement.ejs | 种子育苗批次管理、标签打印、定植记录 |
| 产量管理 | productionManagement.ejs | 采收产量记录 CRUD |
| 施肥管理 | fertilizeManagement.ejs | 施肥记录 CRUD |
| 采购商管理 | - | 供应商信息维护 |
| 种植管理 | - | 定植记录管理 |

### 1.2 新系统现状

V1.1系统已具备以下替代功能：

| 现有功能 | 替代旧模块 | 状态 |
|---------|-----------|------|
| 供应商管理 | 采购商管理 | ✅ 已完善 |
| 采收入库 | 产量管理 | ✅ 已完善 |
| 农事管理 | 施肥管理 | ✅ 已完善 |

### 1.3 缺失功能

| 缺失功能 | 优先级 |
|---------|--------|
| 种源管理 | 🔴 高 |

## 二、关键决策（已确认）

| 项目 | 决策 |
|------|------|
| 数据关联 | 可设定关联，非强制，可独立操作 |
| 二维码 | 保留，前端生成（qrcode库） |
| 数据库 | 暂不考虑，原型演示阶段 |
| 权限 | 默认开放，不做控制 |
| 开发顺序 | 种源管理 → 育苗管理 → 种植管理 |

## 五、页面详细设计

### 5.1 种源管理 (SeedManagement)

#### 功能清单
- 记录查询：多条件筛选（作物类型、作物名称、种源类型、采购商、日期范围）
- 手动录入：作物类型→作物名称→品种→种源类型→采购商→购买日期→登记数量→单位
- 编辑/删除/导出
- 二维码生成（用于批号追溯）

#### 弹窗字段
```
- 作物类型
- 作物名称
- 品种
- 种源类型
- 采购商
- 购买日期
- 登记数量（袋/株）
- 图片上传
- 备注
```

#### 核心字段映射（旧→新）
```
ManageSeedOID → seedId
ManageSeedNum → seedCode
CropsType → cropTypeId
Crops → cropId
PurchasersOID → purchaserId
ProvenanceOID → seedTypeId
PurchaseDate → purchaseDate
Bag/UnitBag → quantity
seedlingCount → usedCount
```

### 5.2 育苗管理 (SeedlingManagement)

#### 功能清单
- 记录查询：多条件筛选（温室位置、批次号、作物名称、记录人、日期范围）
- 手动录入：关联种源批号→作物→温室→育苗数量→定植数量
- 编辑/删除/导出
- 标签打印（二维码）
- 状态：育苗中/已定植

#### 核心字段映射（旧→新）
```
ManageSeedlingOID → seedlingId
SeedlingDate → seedlingDate
SaplingDate → plantingDate
SeedlingCount → seedlingCount
SaplingCount → plantingCount
IsPlant → status
```

### 5.3 种植管理 (PlantingManagement)

#### 功能清单
- 记录查询：多条件筛选（种植区域、批次号、作物名称、种植模式、日期范围）
- 新增定植：从育苗批次选择 → 选择种植区域 → 记录定植信息
- 查看详情：关联的种源、育苗、施肥、采收记录
- 采收关联：可跳转至采收入库页面
- 导出

#### 核心字段映射（旧→新）
```
ManagePlantOID → plantingId
plantNumber → plantingCode
greenHouseName → greenhouseName
cropsName → cropName
FillTime → plantingDate
```

## 八、技术要点

### 8.1 组件式开发模式
- 所有数据从 `types/` 和 `mockData/` 导入，禁止硬编码
- 枚举值、状态值必须从类型定义导入

### 8.2 UI规范遵循
- 表头样式：`bg-gradient-to-r from-blue-500 to-blue-600 text-white`
- 分页组件：统一使用项目中已封装的分页样式

### 8.3 二维码实现
- 使用 `qrcode` 库在前端生成二维码
- 二维码内容包含批号信息用于追溯

## 十二、备注

1. 本方案为前端原型演示阶段，暂不涉及数据库对接
2. 二维码功能先在前端实现，后续考虑对接后端API
