# 种植管理系统迁移规划方案 V3.0

**文档版本：** V3.0
**编制日期：** 2026-04-26
**目标：** 用V1.1系统替代旧管理模块，保留旧功能并进行功能增强

---

## 一、项目背景与目标

### 1.1 背景
- **旧系统** (D:\iAGS\new): 农业物联网平台，使用 EJS + jQuery EasyUI，有6个管理页面
- **新系统** (V1.1): 基于 React + TypeScript + Ant Design 的现代农业管理系统
- **目标**: 用 V1.1 替代旧管理模块，保留旧功能并进行功能增强

### 1.2 旧系统6个管理页面
| 页面 | 功能 | V1.1现状 | 规划 |
|-----|------|---------|------|
| 种源管理 | 种子/种苗采购入库 | 缺失 | **新增** |
| 育苗管理 | 育苗批次和成苗率管理 | 缺失 | **新增** |
| 种植管理 | 区域种植记录管理 | 缺失 | **新增** |
| 施肥管理 | 施肥记录管理 | 已有农事管理 | 替代 |
| 产量管理 | 产量记录管理 | 已有采收入库 | 替代 |
| 采购商管理 | 供应商管理 | 已有供应商管理 | 替代 |

## 二、系统现状分析

### 2.1 旧系统核心数据结构

**种源管理**:
- seedCode (批号), cropName (作物), seedType (类型), supplierName (供应商)
- purchaseDate, quantity, unit, availableCount, pictures

**育苗管理**:
- seedlingCode (育苗批号), sourceCode (关联种源)
- cropName, seedlingType, siteName, startDate, endDate
- initialCount, survivalCount, survivalRate, lossRate, pictures

**种植管理**:
- plantCode (种植批号), seedlingCode (关联育苗)
- cropName, areaName, plantingCount, plantingDate
- soilPH, soilEC, isHarvest, harvestDate, lossRate, pictures

### 2.2 V1.1系统架构

```
技术栈: React 18.3 + TypeScript + Vite + Ant Design + Tailwind CSS
模式: 组件化开发 (types/data/components/pages)
路由: App.tsx
菜单: Sidebar.tsx
```

## 三、融合原则

| 原则 | 说明 |
|------|------|
| **功能完整保留** | 旧系统所有功能必须完整保留，一一对应迁移 |
| **数据优先** | 旧系统数据后续迁移，新系统直接复用 |
| **平滑过渡** | 逐步接管，不影响日常生产 |
| **风格统一** | 新增页面遵循V1.1 UI规范（Tailwind + Ant Design + 卡片式布局） |
| **功能增强** | 不只复制旧功能，要增加统计、分析、预警能力 |
| **复用最大化** | 已有模块能复用尽量复用 |

## 四、菜单与路由设计

### 4.1 方案: 新建"作物管理"主菜单

**理由**: 种源、育苗、种植是农业生产的前置环节，新建独立菜单更符合业务逻辑，便于后续扩展。

### 4.2 菜单结构

```
作物管理（新增主菜单）
├── 种源管理（新增）      → /crop/seed-source
├── 育苗管理（新增）      → /crop/seedling
└── 种植管理（新增）      → /crop/planting
```

### 4.3 路由配置

```tsx
// App.tsx 新增路由
/crop/seed-source      → SeedSourcePage
/crop/seedling        → SeedlingPage
/crop/planting         → PlantingPage
/crop/planting/:id     → PlantingDetail (种植详情页)
```

### 4.4 图标选择

使用 Lucide React 图标：
- 作物管理主菜单: `Leaf` 或 `Wheat`
- 种源管理: `Sprout`
- 育苗管理: `Flower2`
- 种植管理: `Trees`

### 6.1 类型定义文件

创建 `src/types/crop.ts`，包含:

```typescript
// ========== 枚举定义 ==========
export enum SourceType {
  SEEDLING = 'seedling',
  SEED = 'seed'
}

export enum SeedType {
  SEED = 'seed',
  SEEDLING = 'seedling'
}

export enum SeedlingStatus {
  IN_PROGRESS = 'in_progress',
  TRANSPLANT_READY = 'transplant_ready',
  COMPLETED = 'completed',
  ABNORMAL = 'abnormal'
}

export enum PlantingStatus {
  PLANTED = 'planted',
  GROWING = 'growing',
  HARVESTED = 'harvested',
  CANCELLED = 'cancelled'
}

export enum GrowthStage {
  SEEDLING = 'seedling',     // 育苗期
  FLOWERING = 'flowering',    // 开花期
  FRUITING = 'fruiting',     // 结果期
  MATURE = 'mature'          // 成熟期
}

export enum PrintTemplate {
  SMALL = 'small',
  LARGE = 'large'
}

// ========== 种源类型 ==========
export interface SeedSource {
  id: string;
  seedCode: string;           // 种源批号
  sourceType: SourceType;     // 来源类型
  cropCategory: string;       // 作物种类
  cropName: string;          // 作物名称
  cropVariety: string;        // 作物品种
  supplierId: string;         // 供应商ID
  supplierName: string;       // 供应商名称
  purchaseDate: string;       // 购买日期
  quantity: number;           // 包装数量
  unit: string;              // 单位（袋/株/粒）
  unitPrice: number;          // 单价
  totalAmount: number;        // 总金额
  initialCount: number;       // 初始数量
  availableCount: number;     // 可用数量
  pictures: string[];         // 图片列表（Base64）
  remarks?: string;           // 备注
  status: 'sufficient' | 'low' | 'depleted';
  traceabilityCode?: string;   // 溯源码
  printCount: number;         // 打印次数
  createBy: string;
  createTime: string;
  updateTime: string;
}

// ========== 每日记录类型 ==========
export interface DailyRecord {

// ========== 育苗类型 ==========
export interface Seedling {
  id: string;

  sourceId: string;           // 关联种源ID
  sourceCode: string;         // 关联种源批号
  cropName: string;           // 作物名称
  cropVariety: string;        // 作物品种
  seedlingType: string;       // 育苗方式
  siteId: string;            // 场地ID
  siteName: string;           // 场地名称
  startDate: string;          // 育苗开始日期
  expectedEndDate?: string;   // 预计结束日期
  endDate?: string;           // 实际成苗日期
  initialCount: number;       // 初始数量
  survivalCount: number;      // 成活数量
  plantedCount: number;       // 已定植数量
  survivalRate: number;       // 成苗率（计算）
  lossCount: number;          // 损耗数量
  lossRate: number;           // 损耗率（计算）
  isFinished: boolean;        // 是否完成
  status: SeedlingStatus;
  transplantBatchId?: string; // 关联定植批次ID
  dailyRecords: DailyRecord[]; // 每日记录
  pictures: string[];         // 图片列表（Base64）
  qualityGrade?: string;       // 质量等级
  printCount: number;         // 打印次数
  remarks?: string;
  createBy: string;
  createTime: string;
  updateTime: string;
}

// ========== 种植类型 ==========
export interface Planting {
  id: string;
  plantCode: string;          // 种植批号
  sourceType: SourceType;     // 来源类型（seedling/provenance）
  sourceId: string;          // 来源ID
  sourceCode: string;         // 来源批号
  cropName: string;           // 作物名称
  cropVariety: string;        // 作物品种
  areaId: string;            // 种植区域ID
  areaName: string;           // 种植区域名称
  rootName: string;          // 父区域名称
  plantingCount: number;      // 定植数量
  plantingDate: string;       // 定植日期
  soilPH?: number;            // 土壤PH值
  soilEC?: number;            // 土壤EC值
  transplantCount?: number;    // 移植数量
  transplantDate?: string;     // 移植时间
  isHarvest: boolean;         // 是否采收
  harvestDate?: string;       // 采收日期
  attritionRate: number;      // 损耗率
  printCount: number;         // 打印次数
  traceabilityCode: string;    // 溯源码
  pictures: string[];         // 图片列表（Base64）
  remarks?: string;
  status: PlantingStatus;
  createBy: string;
  createTime: string;
  updateTime: string;
}

// ========== 筛选状态类型 ==========
export interface SeedSourceFilters {
  cropName: string;
  seedCode: string;

  startDate: string;
  endDate: string;

  status: string;
```
