## 三、育苗完整业务流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        育苗管理完整流程                               │
└─────────────────────────────────────────────────────────────────────┘

1. 种源准备
   ├── 内部自繁种源 ──> 种源管理录入 ──> availableCount

3. 每日记录（进度提交）
   └── 每日记录 ──> 温度/湿度/浇水/异常 ──> 成活/定植/损耗数量变化 ──> 状态自动转换

4. 状态转换（自动）
   ├── IN_PROGRESS ──> 成活数量>0 ──> TRANSPLANT_READY

5. 汇总导出
   └── 按条件筛选 ──> 导出Excel（含所有统计字段）

6. 标签打印
   └── 生成育苗标签（包含批号、作物信息、数量等，用于扫描提交）
```

### 阶段1：批号生成 ✅

**文件**：`src/services/seedlingService.ts`

```typescript
/**
 * 生成育苗批号
 * 格式：YM + 年月日(YYYYMMDD) + "-" + 3位流水号
 */
export function generateSeedlingCode(): string {
  const today = new Date();
  const year = today.getFullYear();
  const month = String(today.getMonth() + 1).padStart(2, '0');
  const day = String(today.getDate()).padStart(2, '0');
  const dateStr = `${year}${month}${day}`;
  const counterKey = `crop_seedling_code_${dateStr}`;
  let counter = parseInt(localStorage.getItem(counterKey) || '0', 10);
  counter++;
  localStorage.setItem(counterKey, counter.toString());
  return `YM${dateStr}-${counter.toString().padStart(3, '0')}`;
}
```

## 六、状态自动转换逻辑（已实现）

```typescript
// 状态自动转换规则
if (record.abnormality && status !== ABNORMAL) {
  // 有异常情况 → 标记为异常
  newStatus = SeedlingStatus.ABNORMAL;
} else if (status === IN_PROGRESS && newSurvivalCount > 0) {
  // 成活数量 > 0 → 从进行中转为待定植
  newStatus = SeedlingStatus.TRANSPLANT_READY;
} else if (newPlantedCount >= newSurvivalCount && newSurvivalCount > 0) {
  // 定植数量 >= 成活数量 → 从待定植转为已完成
  newStatus = SeedlingStatus.COMPLETED;
  isFinished = true;
  endDate = today;
}
```
