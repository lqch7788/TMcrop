# 种植管理系统全生命周期闭环追踪方案 V3.0

## Context

种植管理系统当前由多个相对独立的模块组成：**生产计划、种源管理、育苗管理、种植管理、采收入库**。这些模块各自运作，数据不互通，形成了"数据孤岛"问题。

**核心架构（已确认）**：

本系统的**双核心驱动 + 库存中心化**架构：
1. **品种库** = 品种数据的 Single Source of Truth（所有作物品种名称和编码都从品种库获取）
2. **生产计划** = 所有生产活动的指挥棒（种源采购、育苗、定植、采收都要依据计划）
3. **统一库存中心** = 通过 `instance_id` 实现全链路库存追溯 + 流水追踪

**现有数据模型分析**：

| 模块 | 关键字段 | 与双核心关联 | 问题 |
|------|---------|------------|------|
| 作物品种库 | cropCode(11位), 生长周期参数 | 品种数据基础 | 系统基础表 |
| 生产计划 | batchId, planCode, items | 驱动所有下游模块 | **与下游完全脱节** |
| 种源管理 | varietyId, varietyName | 品种库 + 依计划采购 | **未继承品种参数** |
| 育苗管理 | seedId, varietyId | 品种库 + 依计划培育 | **未基于品种参数推算** |
| 种植管理 | seedlingId, varietyId | 品种库 + 依计划定植 | **无品种参数传递** |
| 采收入库 | variety (名称) | 品种库 + 依计划采收 | **无完整追溯链** |

**发现的关键问题**：

1. **生产计划与下游完全脱节** - 计划批准后没有触发任何下游动作
2. **品种库生长周期参数未被使用** - 品种库有参数但下游模块没有继承
3. **品种选择存在不一致** - 部分模块用 varietyId，部分用 varietyName
4. **追溯链不完整** - 采收入库只能看到品种名称，无法追溯到种源、育苗批次
5. **库存分散管理** - 各模块独立管理库存，缺乏统一追溯

**规划目标**：
1. **双核心驱动** - 品种库 + 生产计划共同驱动所有下游模块
2. **统一库存中心** - 通过 `instance_id` + `inventory_transaction` 实现全链路追溯
3. **计划贯穿全程** - 种源采购、育苗培育、定植、采收都依据生产计划
4. **全流程可视化** - 实现从计划到采收的全流程追踪和可视化
5. **质量追溯** - 实现农产品全生命周期质量追溯
6. **统一入库** - 所有物资必须先入库才能被下游引用
7. **循环闭环** - 采收产物可回流到上游库存
8. **并发安全** - 乐观锁机制防止库存超卖

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **品种库为唯一种源** | 所有模块的作物名称、编码、类别都从`CropVariety`选择，禁止手动输入 |
| **计划为必填关联** | 种源、种苗、作物订单必须关联`ProductionPlan`，否则无法创建 |
| **统一入库原则** | 种子、种苗、作物无论外购还是自产，都必须先入库登记 |
| **库存中心化** | 通过`instance_id`实现全链路库存追溯 |
| **库存流水追踪** | 每次库存变动记录流水，实现完整的变动历史 |
| **供应商联动** | 外购物资必须关联供应商管理模块（内部供应/基地/外部） |
| **循环闭环** | 采收种子→种源入库，采收种苗→育苗入库（可回流） |
| **多基地支持** | 支持集团公司下多基地的数据关联 |
| **并发安全** | 库存操作使用乐观锁/悲观锁机制 |

```sql
-- 库存中心表（核心追溯表）
-- 存储每个入库实体的完整信息，通过 instance_id 追溯
CREATE TABLE inventory_stock (
  id TEXT PRIMARY KEY,
  instance_id TEXT NOT NULL UNIQUE,  -- 实例ID（追溯核心，格式：INS+年月日+流水号）

  -- 库存类型
  stock_type TEXT NOT NULL,         -- seed|seedling|crop|harvest

  -- 来源类型
  source_type TEXT NOT NULL,        -- external_purchase|internal_production|harvest

  -- 作物信息（关联品种库 - 必填）

  crop_category TEXT,
  crop_name TEXT NOT NULL,
  crop_variety TEXT,

  -- 生产计划关联（必填）
  production_plan_id TEXT NOT NULL,
  production_plan_code TEXT NOT NULL,

  -- 数量信息
  initial_quantity INTEGER NOT NULL, -- 初始入库数量
  current_quantity INTEGER NOT NULL,  -- 当前库存数量（核心）
  unit TEXT,

  -- 供应商信息
  supplier_id TEXT,
  supplier_name TEXT,
  supplier_is_internal BOOLEAN DEFAULT FALSE,  -- true=自产, false=外购

  -- 基地信息（自产时必填）
  base_id TEXT,
  base_name TEXT,

  -- 溯源关系（父子链）

  source_document_type TEXT,        -- seed_source|seedling|planting
  source_document_id TEXT,
  source_document_code TEXT,

  -- 状态
  status TEXT DEFAULT 'in_stock',  -- in_stock|allocated|depleted

  -- 并发控制（乐观锁）

  -- 审计字段
```

### 3.2 并发控制实现

```typescript
/**
 * 出库操作 - 完整乐观锁实现
 */
export function outbound(
  instanceId: string,
  quantity: number,
  expectedVersion: number,
  businessInfo: BusinessInfo
): OutboundResult {
  // 1. 读取当前库存
  const stock = getInventoryStockByInstanceId(instanceId);
  if (!stock) {
    return { success: false, error: '库存记录不存在' };
  }

  // 2. 版本校验
  if (stock.version !== expectedVersion) {
    return {
      success: false,
      error: '库存已被其他操作修改，请刷新后重试',
      currentVersion: stock.version
    };
  }

  // 3. 扣减校验
  const canOutboundResult = canOutbound(instanceId, quantity);
  if (!canOutboundResult.canOutbound) {
    return { success: false, error: canOutboundResult.error };
  }

  // 4. 计算新数量
  const newQuantity = stock.current_quantity - quantity;
  const newVersion = stock.version + 1;

  // 5. 更新库存（原子操作 + 乐观锁）
  const updated = updateInventoryStockWithVersion(instanceId, {
    current_quantity: newQuantity,
    version: newVersion,
    update_time: new Date().toISOString()
  }, expectedVersion);

  if (!updated) {
    return { success: false, error: '更新失败，库存已被其他操作修改' };
  }

  // 6. 记录流水
  const transaction = createTransaction({
    instance_id: instanceId,
    transaction_type: TransactionType.OUTBOUND,
    quantity_change: -quantity,
    quantity_before: stock.current_quantity,
    quantity_after: newQuantity,
    business_type: businessInfo.businessType,
    business_id: businessInfo.businessId,
    business_code: businessInfo.businessCode,
    operator: businessInfo.operator,
    operate_time: new Date().toISOString()
  });

  return { success: true, transaction, newVersion };
}

/**
 * 校验库存是否允许扣减
 */
export function canOutbound(instanceId: string, quantity: number): CanOutboundResult {
  const stock = getInventoryStockByInstanceId(instanceId);

  if (!stock) {
    return {
      canOutbound: false,
      currentQuantity: 0,
      frozenQuantity: 0,
      availableQuantity: 0,
      error: '库存记录不存在'
    };
  }

  // 计算可用数量 = 当前数量 - 冻结数量
  const frozenQuantity = getFrozenQuantity(instanceId);
  const availableQuantity = stock.current_quantity - frozenQuantity;

  if (availableQuantity < quantity) {
    return {
      canOutbound: false,
      currentQuantity: stock.current_quantity,
      frozenQuantity,
      availableQuantity,
      error: `库存不足：当前可用 ${availableQuantity}，需要 ${quantity}`
    };
  }

  return {
    canOutbound: true,
    currentQuantity: stock.current_quantity,
    frozenQuantity,
    availableQuantity
  };
}
```

## 四、模块联动流程

### 4.1 数量联动规则

| 操作 | 触发条件 | 联动效果 |
|------|---------|---------|
| 育苗创建 | 从种源入库选择来源 | 自动扣减种源 `current_quantity` |
| 育苗完成 | 创建种苗入库 | `source='internal_production'`，关联育苗记录 |
| 种植创建 | 从种源/种苗入库选择来源 | 自动扣减对应入库的 `current_quantity` |
| 种植完成 | 创建成品入库 | `source='internal_production'`，关联种植记录 |
| 采收创建 | 从成品入库选择来源 | 创建采收记录，扣减成品 `current_quantity` |
| 销售出库 | 从成品入库选择来源 | 自动扣减成品入库的 `current_quantity` |
| 循环闭环 | 采收种子/种苗 | 创建新的种源/种苗入库，可回流 |

### 6.1 预警类型定义

```typescript
interface InventoryAlert {
  alertId: string;
  alertType: 'low_stock' | 'expiring' | 'expired' | 'slow_moving';
  alertLevel: 'info' | 'warning' | 'critical';

  instanceId: string;
  instanceCode: string;
  cropName: string;
  variety: string;

  currentQuantity: number;
  threshold: number;

  message: string;

}
```

### 6.2 预警规则配置

| 预警类型 | 触发条件 | 等级 | 说明 |
|---------|---------|------|------|
| 低库存预警 | `current_quantity < min_stock_threshold` | warning | 库存低于最低阈值 |
| 库存耗尽 | `current_quantity = 0` | critical | 库存已耗尽 |
| 即将过期预警 | `保质期 < 7天` | warning | 临期提醒 |
| 已过期预警 | `保质期 < 0` | critical | 已过期 |
| 呆滞库存 | `无流动天数 > 90` | info | 长期未使用 |

### 6.3 预警服务实现

```typescript
/**
 * 获取库存预警列表
 */
export function getInventoryAlerts(): {
  lowStockAlerts: InventoryAlert[];
  expirationAlerts: InventoryAlert[];
  expiredAlerts: InventoryAlert[];
  slowMovingAlerts: InventoryAlert[];
} {
  const alerts: Record<string, InventoryAlert[]> = {
    lowStockAlerts: [],
    expirationAlerts: [],
    expiredAlerts: [],
    slowMovingAlerts: []
  };

  // 1. 低库存预警检查
  const lowStockThreshold = getSystemConfig('LOW_STOCK_THRESHOLD', 100);
  const allStocks = getInventoryStockList();

  for (const stock of allStocks) {
    if (stock.current_quantity <= lowStockThreshold && stock.current_quantity > 0) {
      alerts.lowStockAlerts.push({
        alertId: generateUUID(),
        alertType: 'low_stock',
        alertLevel: 'warning',
        instanceId: stock.instance_id,
        instanceCode: stock.instance_id,
        cropName: stock.crop_name,
        variety: stock.crop_variety || '',
        currentQuantity: stock.current_quantity,
        threshold: lowStockThreshold,
        message: `${stock.crop_name} 库存不足，当前 ${stock.current_quantity}${stock.unit}`,
        suggestedAction: '请及时补充库存',
        createdAt: new Date().toISOString()
      });
    }

    if (stock.current_quantity === 0) {
      alerts.lowStockAlerts.push({
        alertId: generateUUID(),
        alertType: 'low_stock',
        alertLevel: 'critical',
        instanceId: stock.instance_id,
        instanceCode: stock.instance_id,
        cropName: stock.crop_name,
        variety: stock.crop_variety || '',
        currentQuantity: 0,
        threshold: lowStockThreshold,
        message: `${stock.crop_name} 库存已耗尽`,
        suggestedAction: '请立即补充库存',
        createdAt: new Date().toISOString()
      });
    }
  }

  // 2. 返回所有预警
  return alerts;
}
```

## 十三、ADR（架构决策记录）

### Decision: 双核心驱动 + 库存中心化 + 流水追踪 + 循环闭环架构

### Drivers
1. **数据规范性**：品种信息统一从品种库获取，避免各模块数据不一致
2. **业务可控性**：所有业务订单必须关联生产计划，便于统筹管理
3. **追溯完整性**：通过 instance_id 实现全链路追溯，流水记录完整变化
4. **库存一致性**：统一入库+自动扣减+流水追踪确保库存准确
5. **循环利用**：采收种子/种苗可回流到上游库存
6. **并发安全**：乐观锁机制（version 字段）防止库存超卖

### Alternatives considered

**方案A（分散库存）**：各业务表独立管理库存数量
- 优点：改动较小
- 缺点：无法实现统一追溯，库存一致性难以保证

**方案B（集中库存+悲观锁）**：所有库存操作通过统一服务，使用悲观锁
- 优点：一致性有保障
- 缺点：性能差，并发能力受限

### Why chosen
- 用户明确要求完整追溯链
- 需要支持循环闭环（采收回流）
- 并发场景下需要保证库存一致性

### Consequences
- 需要新增 `inventory_stock`、`inventory_transaction`、`inventory_freeze` 三张表
- 各模块创建/使用时需要调用库存服务
- 需要实现乐观锁机制处理并发
- 现有数据需要迁移或重新入库
- 需要实现完整的溯源 API

### Follow-ups
- 评估是否需要在品种库中维护"供应商推荐"
- 考虑是否需要在生产计划中设置库存预警
- 考虑是否需要批次管理和有效期管理
- 考虑是否需要支持库存调拨功能

### 14.2 事务边界定义

**事务边界原则**：
- 单个库存实例的 inbound/outbound 操作在一个事务内
- 多表联动（如育苗扣减种源 + 创建种苗库存）必须在一个事务内
- 跨多个库存实例的操作使用分布式事务或补偿机制

**事务范围定义**：

**代码实现示例**：

```typescript
/**
 * 带事务的库存扣减
 */
async function decreaseInventoryWithTransaction(
  instanceId: string,
  quantity: number,
  businessInfo: BusinessInfo
): Promise<{ success: boolean; error?: string }> {
  const MAX_RETRIES = 3;

  for (let attempt = 0; attempt < MAX_RETRIES; attempt++) {
    const connection = await db.getConnection();

    try {
      await connection.beginTransaction();

      // 1. 查询当前库存（带行锁）
      const [rows] = await connection.query(`
        SELECT current_quantity, version
        FROM inventory_stock
        WHERE instance_id = ? AND current_quantity >= ?
        FOR UPDATE
      `, [instanceId, quantity]);

      if (rows.length === 0) {
        throw new Error(`库存不足或不存在: ${instanceId}`);
      }

      const currentQty = rows[0].current_quantity;
      const newQty = currentQty - quantity;

      // 2. 更新库存（乐观锁检查）
      await connection.execute(`
        UPDATE inventory_stock
        SET current_quantity = ?, version = version + 1, update_time = NOW()
        WHERE instance_id = ? AND version = ?
      `, [newQty, instanceId, rows[0].version]);

      // 3. 记录流水
      await connection.execute(`
        INSERT INTO inventory_transaction (
          id, instance_id, transaction_type, quantity_change,
          quantity_before, quantity_after,
          business_type, business_id, business_code,
          operator, operate_time, create_time
        ) VALUES (?, ?, 'outbound', ?, ?, ?, ?, ?, ?, ?, NOW(), NOW())
      `, [
        generateUUID(), instanceId, -quantity,
        currentQty, newQty,
        businessInfo.businessType, businessInfo.businessId, businessInfo.businessCode,
        businessInfo.operator
      ]);

      await connection.commit();
      return { success: true };

    } catch (error) {
      await connection.rollback();

      if (error.code === 'ER_LOCK_WAIT_TIMEOUT' && attempt < MAX_RETRIES - 1) {
        await sleep(100 * (attempt + 1)); // 指数退避
        continue;
      }

      return { success: false, error: error.message };
    } finally {
      connection.release();
    }
  }

  return { success: false, error: '事务执行失败' };
}
```

```typescript
enum InventoryAlertType {
```

**预警服务实现**：

```typescript
/**
 * 库存预警服务
 */
class InventoryAlertService {
  private rules: InventoryAlertRule[] = DEFAULT_ALERT_RULES;

  /**
   * 检查库存是否触发预警
   */
  async checkAlerts(instanceId: string): Promise<InventoryAlert[]> {
    const stock = await getInventoryStockByInstanceId(instanceId);
    if (!stock) return [];

    const alerts: InventoryAlert[] = [];

    for (const rule of this.rules) {
      if (!rule.enabled) continue;

      const triggered = this.evaluateRule(rule, stock);
      if (triggered) {
        // 检查是否已发送过提醒（避免重复）
        const alreadySent = await this.checkRecentAlert(instanceId, rule.type);
        if (!alreadySent) {
          alerts.push({
            instanceId,
            type: rule.type,
            message: this.generateAlertMessage(rule.type, stock),
            severity: this.getSeverity(rule.type),
            stock,
            rule
          });

          // 记录已发送
          await this.recordAlert(instanceId, rule.type);
        }
      }
    }

    return alerts;
  }

  /**
   * 评估规则是否触发
   */
  private evaluateRule(rule: InventoryAlertRule, stock: InventoryStock): boolean {
    switch (rule.type) {
      case InventoryAlertType.LOW_STOCK:
        return stock.currentQuantity <= (rule.conditions.minQuantity || 0);

      case InventoryAlertType.OVERSTOCK:
        return stock.currentQuantity >= (rule.conditions.maxQuantity || Infinity);

      case InventoryAlertType.EXPIRY_WARNING:
        if (!stock.expiryDate) return false;
        const daysToExpiry = differenceInDays(new Date(stock.expiryDate), new Date());
        return daysToExpiry <= (rule.conditions.expiryDays || 0);

      case InventoryAlertType.SLOW_MOVING:
        if (!stock.lastMovementDate) return false;
        const daysNoMovement = differenceInDays(new Date(), new Date(stock.lastMovementDate));
        return daysNoMovement >= (rule.conditions.noMovementDays || 0);

      default:
        return false;
    }
  }
}

/**
 * 预警通知接口
 */
async function sendInventoryAlert(alert: InventoryAlert) {
  const { rule, stock } = alert;

  // 系统推送
  if (rule.notifications.systemPush) {
    await notificationService.push({
      title: `库存预警: ${alert.message}`,
      content: alert.message,
      targetUsers: await getUsersByBase(stock.baseId),
      data: { instanceId: stock.instanceId }
    });
  }

  // 邮件通知
  if (rule.notifications.email?.length) {
    await emailService.send({
      to: rule.notifications.email,
      subject: `【库存预警】${alert.message}`,
      body: generateAlertEmailBody(alert)
    });
  }
}
```

```typescript
 */
async function validateOutbound(
  instanceId: string,
  requestedQuantity: number,
  policy: NegativeStockPolicy = NegativeStockPolicy.FORBIDDEN
): Promise<{ valid: boolean; error?: string; canProceed?: boolean }> {
  const stock = await getInventoryStockByInstanceId(instanceId);

  if (!stock) {
    return { valid: false, error: `库存实例不存在: ${instanceId}` };
  }

  const availableQuantity = stock.currentQuantity - stock.frozenQuantity;
  const willBeNegative = availableQuantity - requestedQuantity < 0;

  switch (policy) {
    case NegativeStockPolicy.FORBIDDEN:
      if (willBeNegative) {
        return {
          valid: false,
          error: `库存不足：当前可用 ${availableQuantity}，需要 ${requestedQuantity}`,
          canProceed: false
        };
      }
      return { valid: true, canProceed: true };

    case NegativeStockPolicy.ALLOW_WARNING:
      if (willBeNegative) {
        await logWarning({
          type: 'negative_stock_warning',
          instanceId,
          currentQuantity: availableQuantity,
          requestedQuantity,
          deficit: Math.abs(availableQuantity - requestedQuantity)
        });
      }
      return { valid: true, canProceed: true };

    case NegativeStockPolicy.ALLOW_BORROW:
      return {
        valid: true,
        canProceed: true,
        // 返回借调记录信息，供后续追踪
        borrowInfo: willBeNegative ? {
          canBorrow: true,
          borrowQuantity: Math.abs(availableQuantity - requestedQuantity),
          borrowAccount: 'system_borrow_account',
          dueDate: calculateDefaultDueDate()
        } : undefined
      };
  }
}
```

```typescript
/**

// 冻结记录
interface InventoryFreeze {
  id: string;
  instanceId: string;
  quantity: number;              // 冻结数量
  frozenType: 'manual' | 'allocation' | 'quality_hold' | 'dispute';
  reason: string;
  frozenBy: string;
  frozenAt: string;
  unfreezeAt?: string;          // 定时解冻时间
  status: 'active' | 'partially_unfrozen' | 'unfrozen';
  unfrozenBy?: string;
  unfrozenAt?: string;
  remarks?: string;
}

/**
 * 冻结库存
 */
async function freezeInventory(
  instanceId: string,
  quantity: number,
  freezeType: InventoryFreeze['frozenType'],
  reason: string,
  options?: {
    frozenBy: string;
    unfreezeAt?: string;
  }
): Promise<{ success: boolean; freezeId?: string; error?: string }> {
  const stock = await getInventoryStockByInstanceId(instanceId);
  const availableQuantity = stock.currentQuantity - stock.frozenQuantity;

  if (quantity > availableQuantity) {
    return { success: false, error: `可冻结数量不足: 可用 ${availableQuantity}` };
  }

  const freezeId = generateUUID();

  await db.transaction(async (trx) => {
    // 创建冻结记录
    await trx.insert(INVENTORY_FREEZE_TABLE).values({
      id: freezeId,
      instanceId,
      quantity,
      frozenType,
      reason,
      frozenBy: options.frozenBy,
      frozenAt: new Date(),
      unfreezeAt: options.unfreezeAt,
      status: 'active'
    });

    // 更新库存冻结数量
    await trx.update(INVENTORY_STOCK_TABLE)
      .set({ frozenQuantity: stock.frozenQuantity + quantity })
      .where({ instanceId });
  });

  return { success: true, freezeId };
}

/**
 * 解冻库存
 */
async function unfreezeInventory(
  freezeId: string,
  unfreezeQuantity?: number,  // 不传则全量解冻
  unfrozenBy?: string,
  remarks?: string
): Promise<{ success: boolean; error?: string }> {
  const freeze = await getInventoryFreezeById(freezeId);

  if (freeze.status === 'unfrozen') {
    return { success: false, error: '该冻结记录已解冻' };
  }

  const actualUnfreezeQty = unfreezeQuantity || freeze.quantity;
  if (actualUnfreezeQty > freeze.quantity - freeze.unfrozenQuantity) {
    return { success: false, error: '解冻数量超出已冻结数量' };
  }

  await db.transaction(async (trx) => {
    // 更新冻结记录
    await trx.update(INVENTORY_FREEZE_TABLE)
      .set({
        unfrozenQuantity: freeze.unfrozenQuantity + actualUnfreezeQty,
        status: (freeze.unfrozenQuantity + actualUnfreezeQty) >= freeze.quantity ? 'unfrozen' : 'partially_unfrozen',
        unfrozenBy,
        unfrozenAt: new Date(),
        remarks
      })
      .where({ id: freezeId });

    // 更新库存冻结数量
    const stock = await getInventoryStockByInstanceId(freeze.instanceId);
    await trx.update(INVENTORY_STOCK_TABLE)
      .set({ frozenQuantity: stock.frozenQuantity - actualUnfreezeQty })
      .where({ instanceId: freeze.instanceId });
  });

  return { success: true };
}

/**
 * 定时解冻任务
 */
async function processScheduledUnfreezes() {
  const now = new Date();

  const dueFreezes = await db.query(`
    SELECT * FROM inventory_freeze
    WHERE status = 'active' AND unfreeze_at <= ?
  `, [now]);

  for (const freeze of dueFreezes) {
    await unfreezeInventory(freeze.id, undefined, 'system', '定时解冻');
  }
}
```

**乐观锁实现**：

```typescript
/**
 * 乐观锁版本控制
 */
interface InventoryStockWithVersion {
  // ... 其他字段
  version: number;          // 版本号，每次更新+1
  lastModifier?: string;   // 最后修改人
  lastModifyTime?: string; // 最后修改时间
}

/**
 * 带乐观锁的库存更新
 */
async function updateInventoryWithOptimisticLock(
  instanceId: string,
  updates: Partial<InventoryStock>,
  expectedVersion: number
): Promise<{ success: boolean; newVersion?: number; error?: string }> {
  const result = await db.execute(`
    UPDATE inventory_stock
    SET
      ${buildUpdateSet(updates)},
      version = version + 1,
      last_modifier = ?,
      last_modify_time = NOW()
    WHERE instance_id = ? AND version = ?
  `, [updates.lastModifier, instanceId, expectedVersion]);

  if (result.affectedRows === 0) {
    // 版本冲突
    const current = await getInventoryStockByInstanceId(instanceId);
    return {
      success: false,
      error: `并发冲突：当前版本 ${current.version}，预期版本 ${expectedVersion}`,
      newVersion: current?.version
    };
  }

  return { success: true, newVersion: expectedVersion + 1 };
}
```
