# 作物管理模块 - 手动操作演示指南

> 本指南详细说明如何在 V1.1 系统的各个页面上手动操作，完整演示从订单到采收的数据流转过程。
>
> 版本：v1.0
> 生成时间：2026-05-01

---

## 一、操作前准备

### 1.1 确认数据环境

在开始之前，请确认系统中已有以下基础数据：

| 数据类型 | 位置 | 确认方式 |
|---------|------|---------|
| 品种库 | 订单新增/实例创建时选择 | 品种下拉框有选项 |
| 场地/大棚 | 育苗/种植时选择 | 场地下拉框有选项 |
| 生产计划（可选） | 种源关联时选择 | 生产计划下拉框有选项 |

### 1.2 操作顺序

```
步骤1: 订单管理 → 创建6个订单
    ↓
步骤2: 订单详情 → 为每个订单创建2个实例
    ↓
步骤3: 种源管理 → 为每个实例创建2条种源
    ↓
步骤4: 育苗管理 → 为每个实例创建1条育苗，并进行定植
    ↓
步骤5: 种植管理 → 查看种植记录（定植后自动创建）
    ↓
步骤6: 采收管理 → 为部分实例创建采收记录
    ↓
步骤7: 实例追溯 → 验证完整溯源链
```

## 三、步骤2：为每个订单创建2个实例

### 3.1 操作入口

页面路径：`作物管理` → `实例追溯`
或者从订单详情页进入

### 3.2 操作方式一：从订单详情创建

1. 在 **订单管理** 页面，点击某个订单的 **"详情"** 按钮
2. 在订单详情页，点击 **"新增实例"** 按钮
3. 填写实例信息
4. 点击 **"保存"**

### 3.3 操作方式二：直接从实例追溯页面创建

1. 在 **实例追溯** 页面，点击 **"新增实例"** 按钮
2. 填写实例信息
3. 选择关联订单（可选）
4. 点击 **"保存"**

2. 点击 **"定植"** 按钮
3. 填写定植信息：

   - **种植区域**：选择"玻璃温室A区"或"玻璃温室B区"

## 六、步骤5：查看种植记录

页面路径：`作物管理` → `种植管理`

### 6.2 说明

1. 创建一条种植记录
2. 关联到对应的育苗和实例
3. 更新实例的已定植数量和状态

### 6.3 验证种植记录

1. 进入 **种植管理** 页面
2. 找到刚才定植创建的种植记录

   - 种植批号
   - 关联的实例编号

   - 状态

## 十、注意事项

### 10.1 关联重要性

**所有记录必须正确关联到实例**，否则溯源链将不完整。请特别注意：
- 种源创建时 → 必须选择"关联实例"
- 育苗创建时 → 必须选择"关联实例"和"关联种源"
- 种植创建时 → 通常自动关联（由定植操作产生）
- 采收创建时 → 必须选择"关联实例"

### 10.2 操作顺序

虽然系统不强制要求按顺序操作，但建议按以下顺序进行：
1. 先创建订单
2. 再创建实例（并关联到订单）
3. 再创建种源（并关联到实例）
4. 再创建育苗（并关联到实例和种源）
5. 执行定植（自动创建种植记录）
6. 再创建采收（并关联到实例）

### 10.3 验证节点

建议在完成每个步骤后，都去实例追溯页面验证一下：
- 订单创建后 → 查看实例是否关联
- 种源创建后 → 查看实例是否有种源记录
- 育苗定植后 → 查看实例已定植数量是否更新
- 采收创建后 → 查看实例已采收数量是否更新
