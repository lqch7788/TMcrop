# 种植管理系统 - 人工管理模块重组综合规划方案

**项目**: 种植管理系统 V1.02
**模块**: 人工管理 + 农事管理 重组
**版本**: v2.0（综合版）
**日期**: 2026-04-04

---

## 一、现状分析

### 1.1 当前问题
- 人工管理模块有 **20个子菜单**，菜单过于分散
- 功能模块之间缺乏流程串联
- 与农事管理等其他模块的数据对接不清晰
- Tab状态无法URL化，无法书签和分享

### 1.2 三个规划版本的优点整合

| 规划版本 | 核心优点 |
|---------|---------|
| V1.0(我的) | 清晰5菜单结构、详细ASCII页面布局、侧边栏图标设计、数据流图、UI规范 |
| V3.0 | Tab状态URL化、员工全生命周期流程、统一容器组件、零破坏演进、旧路由兼容 |
| V2.0 | P0-P2优先级、详细数据结构、考勤规则配置、技能等级体系、9周路线图 |

---

## 二、核心设计原则

1. **Tab状态URL化**: `?tab=xxx` 支持书签和分享
2. **容器即页面，旧组件即内容**: 不需要重写业务逻辑
3. **零破坏演进**: 通过路由重定向平滑过渡
4. **共享组件下沉**: 通用组件复用
5. **任务中心作为统一入口**: 农事任务+人工任务统一派发

## 五、模块间对接设计

### 5.1 农事任务派发 → 任务中心
```
农事任务派发 → 选择地块+作物+工序 → 关联计件工序表
            → 选择执行班组 → 从[班组分配]获取
            → 生成任务工单 → 写入[任务工单]
            → 自动排班 → 写入[排班调度中心]
            → 执行结果 → 写入[工作日志]
            → 考勤同步 → 计入[计件工资]和[工资管理]
```

### 5.2 巡田监测 → 任务中心
```
巡田发现问题 → 自动生成工作日志
            → 严重问题 → 创建任务工单 → 派发工人
            → 巡田记录 → 计入[绩效考核]
```

### 5.3 采收入库 → 考勤+工资
```
采收入库 → 记录采收人员 → 从[员工档案]获取
        → 记录工时 → 写入[工人考勤]
        → 记录产量 → 计入[计件工资]
                  → [工资管理] 月末汇总
```

## 九、数据流设计

### 核心数据关系
```
作物批次(FarmBatch)
       │
       │ 关联
       ▼
农事任务 ──派发──▶ 执行任务 ──执行──▶ 工作日志
   │                  │                    │
   │                  │ 关联               │ 关联
   ▼                  ▼                    ▼
员工(Worker)      考勤记录            工资结算
       │                  │                    │
       │ 班组             │ 汇总              │
       ▼                  ▼                    ▼
    班组(Team)         工资管理            薪酬管理
```

### 关键字段关联
| 源模块 | 目标模块 | 关联字段 | 说明 |
|--------|---------|---------|------|
| 农事任务 | 执行任务 | taskId, batchId | 任务关联作物批次 |
| 执行任务 | 员工 | workerId | 执行人 |
| 执行任务 | 考勤 | workerId, date | 自动打卡 |
| 执行任务 | 工作日志 | taskId, workerId | 日志记录 |
| 工作日志 | 工资结算 | workerId, month | 计件/工时核算 |
