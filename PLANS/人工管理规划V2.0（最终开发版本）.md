## 用户需求确认

| 问题 | 回答 | 影响 |
|------|------|------|
| 临时工比例 | **高（50%以上）** | 临时工管理P0优先级，需快速入职+日结功能 |
| 工资计算 | **混合制** | 固定岗位=基本工资+加班费+奖金；临时工=按天/小时 |

## 二、重组后的5合1模块结构

### 2.1 五大模块定位

| 模块 | 定位 | 核心职责 |
|------|------|---------|
| **任务中心** | 统一任务管理 | 农事任务 + 人工任务 统一派发、执行、跟踪 |
| **考勤管理** | 工时管理 | 打卡、排班、请假、加班一体化管理 |
| **人事管理** | 人力资源 | 入职到离职的全生命周期 |
| **薪酬管理** | 薪资结算 | 工资、计件、预算、成本分析 |
| **运营分析** | 数据洞察 | 人效、风险、考核、预警 |

## 四、任务中心核心枢纽设计

### 4.1 任务来源分类

| 任务类型 | 来源 | 派发方式 | 特点 |
|---------|------|---------|------|
| 农事任务 | 农事任务派发 | 手动/智能 | 周期性农事 |
| 巡田任务 | 巡田监测 | 自动生成 | 发现问题触发 |
| 采收任务 | 采收入库 | 手动派发 | 季节性高峰 |
| 临时任务 | 人工创建 | 手动派发 | 应急/临时 |

### 4.2 工单类型细化

| 工单类型 | 说明 | 关联工序 |
|----------|------|----------|
| 播种工单 | 播种作业 | 整地、播种、覆膜 |
| 施肥工单 | 施肥作业 | 基肥、追肥、叶面肥 |
| 灌溉工单 | 灌溉作业 | 滴灌、漫灌、喷灌 |
| 植保工单 | 病虫害防治 | 喷药、杀虫、杀菌 |
| 修剪工单 | 整枝修剪 | 打顶、剪枝、绑蔓 |
| 采收工单 | 采收作业 | 采摘、分级、包装 |
| 巡田工单 | 日常巡检 | 记录、问题上报 |
| 临时工单 | 应急任务 | 临时加班、抢修 |

### 4.3 任务生命周期

```
待派发 ──→ 已派发 ──→ 已接收 ──→ 执行中 ──→ 待验收 ──→ 已完成
   │                                              │
   └──→ 已取消                                    └──→ 已逾期
```
