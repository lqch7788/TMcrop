## 四、模块间功能对接设计

### 4.1 任务中心 - 核心枢纽

**任务中心**是整个系统的核心，作为农事管理和人工管理的统一入口。

#### 4.1.1 任务来源分类

| 任务类型 | 来源模块 | 派发方式 |
|---------|---------|---------|
| 农事任务 | 农事任务派发 | 手动派发 / 智能派工 |
| 巡田任务 | 巡田监测 | 自动生成 |
| 采收任务 | 采收入库 | 手动派发 |
| 临时任务 | 人工创建 | 手动派发 |

#### 4.1.2 任务派发流程

```
1. 选择任务来源 (农事/巡田/采收/临时)
2. 填写任务详情 (名称、园区、地块、优先级)
3. 选择执行人员 (手动选择 或 智能派工推荐)
4. 关联作物批次 (可选)
5. 保存派发
```

#### 4.1.3 任务执行与跟踪

```
任务派发 → 工人接收 → 开始执行 → 更新进度 → 完成任务 → 巡田记录
                ↓
           考勤自动打卡
                ↓
           工作日志记录
                ↓
           工资自动核算
```

### 4.2 农事管理 → 任务中心 迁移

**迁移策略**:
- "农事任务派发"功能 → 合并到"任务管理"作为新建任务的入口
- "巡田监测" → 保留独立页面，巡田结果可转为任务
- "采收入库" → 采收任务可从任务中心派发
- "农事操作记录" → 工作日志的农事部分

### 4.3 人工管理内部对接

```
招聘入职 ──入职办理──→ 员工档案
     │                    │
     │                    ▼
     │               班组分配
     │                    │
     ▼                    ▼
排班调度 ◄──排班计划──┘
     │
     ├──→ 考勤记录 ←──工人考勤
     │
     ├──→ 请假/加班 ←──请假管理/加班管理
     │
     └──→ 工资计算 ←──薪酬管理
              │
              └──→ 计件工资/绩效考核
```

### 7.1 核心数据关系

```
┌─────────────┐
│  作物批次   │
│ (FarmBatch) │
└──────┬──────┘
       │
       │ 关联
       ▼
┌─────────────┐     派发     ┌─────────────┐     执行     ┌─────────────┐

│(FarmTask)  │   智能派工   │(TaskExecute)│   更新      │(WorkLog)   │
└─────────────┘              └──────┬──────┘             └──────┬──────┘
                                    │                            │
                                    │ 关联                       │ 关联
                                    ▼                            ▼
                             ┌─────────────┐              ┌─────────────┐
                             │   员工      │              │   考勤记录  │
                             │  (Worker)  │              │(Attendance) │
                             └──────┬──────┘              └──────┬──────┘
                                    │                            │
                                    │ 班组                       │ 汇总
                                    ▼                            ▼
                             ┌─────────────┐              ┌─────────────┐
                             │   班组      │              │   工资结算  │
                             │   (Team)    │              │  (Payroll) │
                             └─────────────┘              └─────────────┘
```

### 7.2 关键字段关联

| 工作日志 | 工资结算 | `workerId`, `month` | 计件/工时核算 |
